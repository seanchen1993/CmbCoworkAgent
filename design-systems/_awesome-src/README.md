# awesome-design-md import

Brand DESIGN.md files under `design-systems/brand-*` are imported from VoltAgent's `awesome-design-md` collection.

- Source: https://github.com/VoltAgent/awesome-design-md
- License: MIT
- Import note: copied from the repository's `design-md/*/DESIGN.md` files and wrapped with local `meta.json` category metadata for the Design panel selector.

These files describe visual systems inspired by publicly visible brand websites. They are presets for internal design generation, not claims of ownership over those brands.
