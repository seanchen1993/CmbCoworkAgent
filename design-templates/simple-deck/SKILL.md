# 简洁演示稿

用于轻量 HTML 幻灯片、路演叙事或简洁方案展示。

## 参考文件
- `template.html`
- `layouts.md`
- `checklist.md`

## 输出规则
- 生成自包含 HTML 演示稿，默认 6-10 页。
- 每页只承担一个表达任务，并适配 16:9。
- 有需要时加入简单键盘导航。
- 保留一个 edit-mode JSON 块。
