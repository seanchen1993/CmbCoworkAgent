# 市场 W+ React + Ant Design 页面

## 打开方式

解压后，使用 Chrome 或 Edge 双击任意 HTML 文件。五个页面均可独立打开，页头可切换页面。请保留同目录的 `cdn/`、`assets/` 与 `theme.css`。

| 页面 | 文件 | 主要功能 |
| --- | --- | --- |
| 批量导入 | `batch-import.html` | 页面与弹窗导入、拖拽选文件、解析进度、三类反馈、重新上传、模板和错误报告下载 |
| 基础表单 | `basic-form.html` | 纵向标签、必填校验、条件字段、日期、开关、提交与重置 |
| 复杂表单 | `complex-form.html` | 分步填写、动态奖品、日期及预算约束、实时预览、草稿、确认发布 |
| 筛选表格 | `filter-table.html` | 响应式筛选、展开收起、查询重置、选择、分页、排序、列筛选、详情、编辑、复制、导出与删除 |
| 选择列表弹窗 | `select-list.html` | 单选/多选、最左勾选列、关键词搜索、分页、跨页保留选择、确定回填、取消保留原结果 |

## 设计规则

依据用户提供的 Batch Import、Form、Filters、Table 和 Select List 五张原始设计图。主要规则及实现位置见 `DESIGN.md`。

- 标准表单：14px 字号、32px 控件高度、24px 字段间距，纵向标签左对齐。
- 必填项较多时只标注少数“选填”字段，避免同时使用两套提示。
- 短表单按钮随内容左对齐；复杂表单操作固定在底部并左对齐，错误包含字段及全局反馈。
- 筛选区：标签宽 98px、水平间距与内边距 20px、行距 16px；1920/1600/1440px 视口下分别最多为 5/4/3 列，默认两行，末格为操作。
- 表格：默认行高 48px，可切换 40px/56px；文本左对齐，金额右对齐；固定右侧操作列，链接间距 16px，低频操作放入“更多”。
- 选择弹窗：搜索、表格、分页、取消/确定，选择列置于最左侧。

图中未给出精确色值与所有页面尺寸，主色采用视觉近似 `#1774FF`，圆角 2px，其他反馈色沿用 Ant Design 默认值。企业名称、字段内容、奖品及海报为本地示例；海报展示布局和动态内容，并未复刻示例商业广告素材。

## 技术与资源

- React 18.2.0 / ReactDOM 18.2.0、Ant Design 5.28.0、Day.js、Babel 浏览器转换器。
- 使用真实的 Form、Input、Select、DatePicker、Table、Modal、Upload、Steps、Descriptions 等 Ant Design 组件。
- 所有运行资源通过 `./cdn/` 相对路径加载，没有网络脚本、外部字体、接口请求或构建依赖。
- CDN 文件来自 system-html-templates 技能随附的原始资源，并通过清单 SHA-256 校验。
- `assets/企业导入模板.xlsx` 为可下载、可用 Excel 打开的模板。

## 演示边界

批量导入中的 Excel 解析、记录数量和提交结果为模拟。上传前可选择“全部成功 / 部分错误 / 全部错误”覆盖规范状态，文件不会发往服务器。错误报告按当前模拟场景生成。模板中的示例行不决定模拟记录数量。

表单提交、活动发布及表格操作只影响本地演示。表格数据保留于当前页面内存，刷新后恢复初始数据；活动草稿保存在当前浏览器的 localStorage，不能跨浏览器共享，且本地文件存储行为受浏览器策略影响。取消选择弹窗不会提交临时选择。

该交付适用于独立预览和前端原型；接入正式业务时，需要替换模拟数据与上传/提交逻辑，并在工程中预编译 JSX。

验证详情见 `VALIDATION.md`。
