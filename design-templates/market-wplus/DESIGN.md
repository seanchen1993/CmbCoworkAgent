# 市场 W+ 页面规范映射

## 设计依据与实现

- Form 图「表单规则」：标准字号 14px、高度 32px、间距 24px；短表单操作随内容左对齐，复杂表单操作固定底部左对齐。
- Form 图「选填必填」：必填项较多，仅在少量可选字段后标注（选填），不重复星号。
- Filters 图「宽度等分排布」：筛选标签 98px，容器内边距/水平间距 20px，行距 16px；1920/1600/1440 对应 5/4/3 列，默认两行，末格放操作。
- Table 图「尺寸大小」：默认行高 48px，14px 字号，水平间距 12px；大/小密度 56/40px。
- Table 图「对齐/交互」：文本左对齐、数值右对齐、表头排序筛选、选中、展开、空态、固定表头与操作列、长文字省略提示。
- Table 图「操作区」：链接间隔 16px，低频操作收进更多。
- Batch Import 图：.xls/.xlsx 拖拽上传、模板下载、自动解析进度、三类反馈、错误报告、重新上传，页面和弹窗两种载体。
- Select List 图：弹窗标题、搜索、表格、分页、取消/确定；勾选列按图中修订要求固定在最左。
- 色值/圆角图片无法准确取证：主色 #1774FF、2px 圆角为视觉近似；其他反馈色沿用 Ant Design 默认值。业务文案与数据为构造示例。

## 技术与边界
React 18 + Ant Design 5.28.0（技能提供的固定原始资源）。各 HTML 内含 JSX 应用与初始化，公共 CSS 及基础组件共享。所有数据仅存于当前浏览器；草稿使用 localStorage。批量导入的解析与提交明确标记为本地模拟，不声称接入真实业务服务。


## 推定项

图片为规则说明，页面使用企业经营及福利活动构造示例。全局导航为五个独立页面的预览入口。图片明确给出 1920/1600/1440px 三种视口下的列数；对应 CSS 过渡断点取 1800/1500/1200px，更窄视口补充 2/1 列以保证可操作。海报采用代码绘制的示例预览，未复制图片中的商业宣传素材。
