# SaaS 落地页

用于 SaaS 营销页面，首屏需要清楚传达产品类别、价值和可信证据。

## 参考文件
- `template.html`
- `layouts.md`
- `checklist.md`

## 输出规则
- 首屏必须展示产品或具体产品状态，不要只放抽象装饰。
- 包含目标受众、价值主张、工作流证明、价格或 CTA 暗示，以及社会证明。
- 使用当前 DESIGN.md token，文案要具体可信。
- 保留一个 edit-mode JSON 块。
