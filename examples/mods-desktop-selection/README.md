# 体验两个不同插件共同处理所选文字

1. 导入本目录的 ZIP，再导入 `examples/mods-copy-prefix` 的 ZIP，分别批准两个来源。
2. 在“我的 Claw”组合中先只加入“使用所选文字”，保存并应用到当前聊天。
3. 输入 `/selection-board`，打开右侧 Claw 工作台 → 插件与结果。选中一段聊天文字，点“复制所选文字”，再粘贴查看：与所选内容一致。
4. 将另一个来源的“复制时添加标记”加入同一组合，保存并应用，重新打开面板。再次选择、复制、粘贴，内容前面会多出 `[检视摘录]`。
5. 移除标记组件后，选择面板仍可用，复制恢复原内容。加入输入整理或下一步建议组件，也会在各自时机共同参与。

这是两个独立插件接力处理同一次实际操作。保存和应用不会开始任务；选择文字不会自动发给模型。这个示例只复制文字，并没有执行代码检视。需要模型分析时，作者可在组件中明确调用模型接口。

Escape、命令或任务结束会清除旧选择；等待期间的新选择会保留。只读取当前聊天和插件结果，不读取配置页、其他应用或剪贴板。若系统拒绝访问剪贴板，面板会说明失败，不会显示“已复制”。

当前验收机器的 Windows 拒绝剪贴板访问，真实失败回执已验证；这里的正向复制需要系统允许访问剪贴板。底层单元测试覆盖成功写入、多插件改写和失败回执，不能代称当前机器的正向粘贴验收已通过。
