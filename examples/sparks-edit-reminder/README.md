# 编辑提醒

这是独立作者包，消费宿主只读能力
`native.file-edits/changes@1.0.0`，不导入宿主代码。将当前版本加入聊天并批准后，
从扩展页面打开“编辑提醒”。仅查看发现列表不执行 Hook、注册回调或启动订阅。

打开页面先读取真实状态，再创建有界订阅。每 500ms 仅拉取修订后的事件；丢失、
迟到或重新打开时重新读取。提示只来自宿主 `write_file` / `edit_file` 成功完成点。
被拒绝、失败、晚到旧聊天的写入不会成为完成提示。

页面有“明确写入示例文件”按钮，默认写入工作目录中的 `edit-reminder.txt`。
可通过包 options 的 `path` / `text` 调整。按钮沿宿主真实用户操作、写入租约及文件
批准路径执行，不会因为打开页面或收到通知自动写文件。

返回、关闭或禁用页面执行专用清理动作，等待原定时资源实际关闭并退订。清理帧不能
执行新文件、进程、网络、模型动作或打开页面。组件停用、替换和聊天关闭也会关闭
所属资源。状态不可核对时显示 unknown，不把空列表或“已批准”当作编辑成功。

`openAction` 只用于视图初始化：读状态、订阅、受控刷新定时器、自己的状态与视图。
它不能执行文件、进程、网络、模型、工具或嵌套业务动作。实际操作必须放在后续
明确用户按钮中。打开和关闭不消耗普通外部动作的持久回执配额。
