# 体验输入框也能 DIY

这个例子不用模型就能看到组合的不同效果。它不读取代码、不代表已经做了检视或测试。

1. 在普通本地项目聊天开启 Mods，从“上传、授权与完成规则”导入这个目录或包含本目录内容的 ZIP，并批准组件。
2. 打开右侧“我的 Claw”，添加 `input-claw-kit`，选择部分组件。
3. 只选“下一步建议”，保存并应用。聊天输入 `/input-next`。空白输入框会出现灰色建议；按 Tab 或 → 接受，文字仍为小写，且没有自动发送。
4. 清空输入框，在组合里加入“输入整理”，保存并应用，再执行 `/input-next`。接受后文字变成大写，前几个字有标记。这是两个组件共同处理同一次输入的实际效果。
5. 移除“下一步建议”但保留“输入整理”。`/input-next` 不再注册，普通英文输入仍自动整理。移除“输入整理”后，输入恢复原样。

保存更新模板；应用更新当前聊天。任务运行时先结束或取消，再应用新组合。还可以加入其他已批准插件的组件、技能、模型和流程；每个组件做什么以它的说明和实际支持范围为准。

作者注意：建议由组件显式提供，宿主不会默认再调用模型生成建议。输入尚未通过规则时，SDK 的 append/insert 立即返回未填入，避免互相等待；编辑处理函数可以用 `next` 改写编辑或直接返回最终文字。附件和技能选择不进入文字编辑事件。
