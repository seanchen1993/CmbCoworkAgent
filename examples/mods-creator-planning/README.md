# 通用创造者规划建议 Mod

将本目录内容打包为 ZIP，通过应用原有插件安装入口安装、启用并授权。在创造者面板的“创作选项”中，选择 `creator-review-first`，点击“验证并使用所选规划”。也可选择另一版本替换，或点击“撤回策略，使用原生规划”。

此示例使用原有 `prompt.section` 事件及 `name: "creator.planning"`，只返回 `{ text }`，无需新增清单。验证与使用均在原 Function Mod VM 中进行，不执行 `session.start`，没有文件、网络、模型、工具、存储或授权 SDK。建议长度上限 3000 字符，调用有时间限制。

用户选择绑定本地插件身份与精确源码摘要。源变更、停用、卸载、撤权、运行失败或未知结果均回到原生创造者，并提示诊断。不会自动安装、审批、重放任务或恢复旧执行。工具、预算、必需检查和安装凭据仍由宿主执行；停止、安装核对与恢复入口不依赖该 Mod。
