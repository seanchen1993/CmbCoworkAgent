# 独立作者包组成的个人任务工作台

本例验证通用灵件底座，不依赖项目模式或 AutoBiz。

- `provider`：注册真实本地任务、状态、通知、启动与取消动作。
- `consumer`：仅使用公开版本化接口注册独立页面、导航、侧栏、操作入口和设置；通过受控表格、树、图表、列表、日志、表单组合提供方。
- `behavior-prefix`、`behavior-compact`：两个相互独立的替代实现包，竞争 `prompt.suggest` 和 `ui.toast` 两个已接通的真实宿主呈现处理点。

在隔离聊天安装并授权对应包后，点击工作台入口。任务实际使用获准文件或本地进程执行，取消只有在实际资源退出后才成为已取消；关闭工作台只停止界面订阅，不伪造任务结束。

行为登记不会自动生效。打开原生“行为设置”，选择两个替代实现预览会看到冲突；每个处理点选择一个后重新预览并确认应用。作者通过实际 guest handler 的 `next(event.input)` 委托宿主原实现，允许异步处理和结果加工。停用全部恢复宿主原实现。来源、版本或授权改变会撤销当前应用，要求重新预览。

当前替换范围只有输入建议和通知呈现。工具批准、凭据、原始结果、真实状态和执行证据不属于替换范围。注册新处理点仍需原生业务明确接入；本例不代表所有业务模块已支持替换。

授权拒绝、目标或版本过期、清理未确认都会保留明确失败状态。结果未知时应检查实际任务和私有状态，不换请求键盲目重试。运行中的任务随应用退出而终止；本例不承诺退出后后台执行。
