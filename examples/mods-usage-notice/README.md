# 任务用量提示组件

1. 在插件管理页上传 `output/mods-usage-notice.zip`，批准该组件能力。
2. 打开右侧 Claw 工作台，进入“配置”，在自己的组合里选择“任务用量提示”，保存并应用到当前聊天。也可以和其他插件的检视、复制或输入规则组件组合。
3. 在原来的对话输入框输入 `/usage-board`，打开工作台的“插件与结果”。命令只打开面板，不请求模型回答。
4. 正常发送一个任务。模型实际返回输入量后，面板自动更新；没有报告时显示等待，不根据字数猜测。

DIY 的作用：你可以给自己的 Claw 增加这一小块能力，而不改主程序；与选择文字、复制标题、检视等组件独立组合。删除它只去掉这块提示，正常聊天继续使用。

此组件显示最近一次响应使用的上下文，不是累计费用。本地没有 Claude 账户订阅额度，面板不会填假的额度数字。关闭 Mods、撤权或重新选择组合后，以当前有效组件为准。

作者使用官方名称 `session.measure` 监听通知。通知是短期观察入口，最长五秒，结束时关闭在通知里派生的计时器和进程；长期后台工作请在会话启动或明确命令中启动。已被运行时接纳的通知可能因随后取消而没有执行，不会自动重复同一份通知；打开面板时也会主动读取当前用量。
