# Vue 3 多接口联调演示

这是可操作的 Vue 3 订单运营台：概览、搜索/状态筛选、分页、详情抽屉、仓库库存、销售趋势和通知。
9 类本地 GET 接口；8 笔订单、4 个 SKU、2 个仓库。所有数据均为虚构。

## 启动
1. 先在旧演示窗口按 Ctrl+C。解压本包后双击 `start-demo.cmd`，保持窗口打开。
2. 出现 `Vue page: http://127.0.0.1:4179/orders` 后打开页面。无需 npm install，无需外网 CDN。
3. 如果提示找不到 Node.js，在平时运行 npm run dev 的终端进入本目录，执行 `node .\server.cjs`。
4. 如果端口占用，关闭自己启动的旧演示窗口后再试，不要结束未知进程。重启应用不会启动演示服务。

## 在工作台里填写
- 演示入口：`http://127.0.0.1:4179/demo`，含三步指引、复制按钮和两轮对照说明。
- 灵件1.0.2的表单位于聊天顶部，可直接点击“填入演示案例”，然后“开始联调分析”。需要时展开检查范围，阅读报告时收起配置。
- 页面地址：`http://127.0.0.1:4179/orders`
- 接口文档：`http://127.0.0.1:4179/api-docs`
- 本次关注点：复制“工作台填写内容.txt”里的完整测试要求。
- 浏览器控制首次启用后需按应用提示重启。模型应实际打开页面、操作筛选/分页/详情并核对网络响应。

## 两轮对照
第一轮使用“接口文档.txt”（服务地址 /api-docs），其中一部分正确、一部分不符合真实 API。
第二轮可以在聊天顶部直接点“换正确文档对照”，再点开始，不会自动启动第二轮。
第二轮改用“接口文档-正确版.txt”（/api-docs-correct）。页面缺陷保留，便于验证模型能区分文档错误与实现错误。
独立的“验收答案-请勿提交给模型.txt”列出预设问题及正常功能，完成分析后再自行核对。不要在第一轮提供答案。

## 文件
- 演示讲解词.txt：五分钟展示流程、追问建议及成功标准。
- public/index.html：Vue 模板；public/app.js：Composition API 状态与请求。
- public/style.css：响应式运营台界面；public/vendor：固定版本 Vue 与许可证。
- server.cjs：静态资源及模拟 API，Node 内置模块，无依赖安装；仅监听本机。
- 所有 API 均为 GET，不提供修改业务数据的操作。通知接口故意返回503，页面故意包含联调缺陷。

实现使用 Vue 官方支持的本地 global build，无构建步骤；不是静态截图，也不依赖平台业务特例。
文档：https://vuejs.org/guide/quick-start.html#using-vue-from-cdn
