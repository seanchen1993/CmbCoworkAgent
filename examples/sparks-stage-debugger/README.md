# 第三方阶段调试 Mod

此包通过公共 `$.platform` 协议和独立 `Pane` 实现控制界面，既不引用 Electron IPC，也不读取主进程私有缓存。

1. 在原创造会话启用此 Mod，并启用创造者模式。
2. 对支持的 Host file-only 插件完成真实阶段试用，获得阶段进入前快照。
3. 在创造会话保存候选，仅修改目标及后续未被上游共享的 Skill 正文。
4. 打开侧栏“阶段调试工作台”，刷新，明确选择快照和候选，然后准备单阶段或后续流程方案。
5. 检查影响阶段和候选摘要，再转到原生复核。创建分支和启动由原生入口另行确认。
6. 返回控制会话刷新原生结果；`passed` 来自原生执行与检查记录，不能由 Mod 发布成功声明。

仅使用 `platform.read/act` 与 `ui.open/invalidate/resolve`。安装/启用仍需原有 Mods 权限审查；包不请求文件、进程、网络、工具、模型或 MCP 权限。侧栏打开期间只读取摘要，真实按钮通过原生用户动作触发分页读取和方案准备。

隔离分支不加载本 Mod 或其他 Mods。当前仍拒绝配置、context、Hooks、MCP、SharedMods 和外部动作；本包不能取消这些限制。不回退数据库、网络、发布、Git 或原运行。方案和跳转的授权不跨进程恢复，失效或未知结果须重新读取核对，不自动重放。

此示例采用显式刷新，未实现实时订阅。复核请求只返回意图是否已记录、导航是否已派送；没有原生界面回执时，不宣称界面已打开。原生工作区重新读取意图后仅预选参数，必须由用户重新点击准备方案、核对勾选，再创建和启动。
