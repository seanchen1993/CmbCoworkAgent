# 第一个灵件：打招呼

这是完整的最小安装目录，复制后即可修改。两个源码文件与[一步一步教程](../../docs/sparks/plugin-cookbook.md)一致。

1. 在“自定义助手 → 添加功能 → 我已添加 → 从文件夹安装”安装本目录，核对并批准能力。
2. 在“助手组合”加入 `my-first-spark`，点“保存并核对应用”，核对并应用到所选空闲聊天。
3. 发送 `/hello-spark 小明`，应看到“你好，小明！第一个灵件已运行。”。
4. 发送 `/hello-spark`，应看到“你好，新朋友！第一个灵件已运行。”。

从零开发只需改 manifest 的插件 ID、源码中两处命令名和返回文案，再更新、授权并应用。
不需要模型、网络或业务服务，不读取文件，也不创建项目阶段。

`Register` 由作者检查器提供类型声明，无需安装 `claude-code` 运行依赖。在源码仓库根目录执行
`openwork plugin inspect ./examples/sparks-hello --types --strict-compatibility` 可检查类型和兼容性。

需要项目节点说明、跨插件动作或保留旧 Hooks 的阶段复用，继续阅读教程中的对应示例。
