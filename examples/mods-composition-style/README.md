# 两个插件组合成自己的 Claw

这个示例由两个独立安装包组成。`mods-composition-board` 提供看板和按钮；
`mods-composition-style` 改变其它插件的展示。样式插件不需要修改看板的源码。

这两份维护示例已在 1.5.2 修复版实际导入、组合、操作和移除回检通过。
可直接转交的安装包、使用说明与截图见[主版本说明](../../docs/mods-main-version-delivery-2026-10-07.md)。
检视和汇报组件是另一个组件包；本例仅演示跨插件界面组合。

1. 打开 Mods，开启当前会话的 Mods 使用。
2. 上传看板安装包，检查并批准；在对话输入 `/claw-board`，选中命令后执行。
   先看到原文字和“完成一次操作”按钮。点击后计数增加。
3. 上传样式安装包，检查并批准。将两个组件都加入自己的 Claw 组合并保存、应用。
   如果界面提示需要明确重载，使用该入口完成应用。
4. 再执行 `/claw-board`。文字前增加“组合版”，按钮前增加说明，并改名为
   “执行 · 完成一次操作”。点击仍增加原看板的计数。
5. 从组合里移除样式组件并应用，重新打开看板，恢复原来的展示和按钮。

这就是跨插件组合：保留一个插件的功能，再用另一个插件统一改变它的界面。
本示例不会请求模型、运行开发任务或写工程文件。计数只是当前插件实例里的演示值，
重新建立实例后从零开始；它不是历史任务记录。只调整其它组件用构造器绘制的面板，
不会自动改变原聊天正文。原生聊天内容的包装使用另一个原生内容组合示例。

作者主要看样式插件的 `hooks/register.ts`：`await next(e)` 取得下游组件表，
`Text` 和 `Button` 是真正的替换函数。按钮原来的回调由宿主私下保留；样式插件
不能拿到它并直接调用，也不会因为画出按钮获得原插件的权限。
