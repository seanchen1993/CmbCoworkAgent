# 我的交付 Claw：三分钟体验

这是一个可安装的 CMB Function Mods 插件。你可以给它起名字、设置项目交付提醒，
每次主会话正常回答结束后，在回答旁看到自己的交付卡，也能打开可编辑面板。
插件本身不请求模型、不读取代码、不执行命令；它不声称已经检视或测试代码。

## 运行前提

使用包含 Mods v2 的开发版本：`C:\ai\CmbCoworkAgent-mods-v2`、`codex/mods-v2` 分支。
这份插件不能让未包含 Function Mods 的旧版应用获得该能力。
如果当前运行的是旧版或 UAT，请在上述开发工作区使用工程规定的 Node 22 环境执行 `npm run dev`。
本例没有替换当前安装包，也没有修改 UAT 或用户配置。

## 安装

1. 打开一个关联项目目录的普通会话，进入“自定义 → 插件”。
2. 在本地插件安装入口上传 `my-delivery-claw.zip`；也可以选择本 README 所在目录。
3. 启用项目 Mods，在函数插件列表找到 `my-delivery-claw`，检查并授权当前版本。
4. 返回会话，输入 `/my-claw`，打开“我的交付 Claw”面板。

安装目录通常是源目录的副本。修改源码后需重新安装并重新授权摘要；不要假设编辑源文件会热更新已安装副本。

## 按这个顺序体验

```text
/my-claw name 招银研发搭子
/my-claw rule 提交前确认权限边界、异常处理，并列出没有运行的测试。
/my-claw preview
```

此时不用调用模型就能看到：

```text
招银研发搭子 · 预览（未执行任务）
交付提醒：提交前确认权限边界、异常处理，并列出没有运行的测试。
待确认：代码检视 / 功能测试 / 未解决的问题
这是交付提醒，不代表已经完成检视或测试。
```

`name` 和 `rule` 命令会立即回显保存后的交付卡；也可以用 `/my-claw status` 查看当前配置。

再发送一条普通消息，例如“只回复：体验完成”。正常回答结束后，宿主会自动附加同样格式的交付卡，
其中标题改为“本轮已结束”，显示本轮耗时。这里的结束是一轮回答结束，不等于整个开发任务已验收。
普通消息需要你已有的模型配置；插件不会额外调用模型。

输入 `/my-claw off`，再发一条普通消息：不会新增交付卡。
输入 `/my-claw on` 恢复。关闭提醒不会删除已经显示的历史卡片。

也可以直接在 `/my-claw` 面板里改名字、提醒和开关。
重启应用后设置仍按项目保存；输入 `/my-claw last` 可读本项目最近一张交付卡。
UI 的旧附加说明不保证跨应用重启保留，`last` 从插件持久存储读取保存的文本。

## 这就是这里所说的 DIY

你安装了自己的命令、自己的交互面板、自己的项目设置和自己的轮次结束行为。
这些都在 `hooks/register.tsx` 中，不需要修改主 Agent 或 Electron 主程序。
这也不是旧 Hooks 做不到的事情；它展示的是 Function Mods 用一个统一 SDK 把这些能力组合在一起。

可修改 `card()` 改交付卡格式；修改默认 `name/rule` 改初始值。
默认值仅用于尚未保存设置的项目，已有设置请用面板或命令修改。
本例只演示当前已支持的能力，不包含独立 Review Agent、自动修复或阻止任务交付。
