# 代码变更导航

这是通用 Mods 只读侧栏组件。它使用 `devclaw.surface/v2` 的 `interaction: query` 和真实的 `native.git/inspection/1.0.0`，可在任务继续运行时检查用户授权的仓库或 linked worktree。

安装并启用此插件后，在会话侧栏打开“代码变更”。输入目录和该任务的固定起点提交，或点击“读取工作流工作树”选择当前会话的真实目录及起点，然后点击“加载 / 刷新变更”。目录读取由宿主原生确认，插件中的路径本身不是授权。选择文件显示有界 Diff；下一页仍绑定同一比较身份，仓库变化时须刷新。

首期仅支持固定起点至 working 的累计已跟踪变化，另标未跟踪文件。首次成功读取会把提交引用冻结为实际 SHA。页面展示实际目录、起点、HEAD、分支和读取时间；冲突、二进制、截断、权限失败、过期和目录清理均有明确提示。失败或切换选择会清空旧正文。源码和 patch 不会由本组件提交到模型上下文。

工作树创建、分支、提交、调度和清理由原插件或用户脚本管理。本组件只保留当前视图的内存选择，不写业务状态、工作树或 Git index，不调用模型、进程或工作流控制动作。任意外部脚本维护的目录可手动输入；工作流列表仅投影平台已有记录，没有特定 Batch 或业务插件适配。

仓库自定义的 clean filter、textconv 和编码转换程序不会执行。若文件声明了自定义转换，预览会提示采用原始文本；这时与仓库自行转换后的 Git 差异可能不同。常规文本的 CRLF 换行由宿主直接处理，不启动仓库脚本。

受保护路径不读取正文，也不在界面泄漏路径。列表可展示其余获准内容，并标明未检查的受保护路径和子模块数量；这时空列表仅表示可读取范围内没有变更。目录撤权、请求取消、越界或快照失效仍会终止读取，不会伪装成部分成功。

需要支持上述实际能力与 Surface v2 的构建；应用版本 `2.0.0` 本身不能证明协议可用。源码位于 `mods/main.ts`，运行时能力注册在 `on.capability` 中，只有用户点击加载后才请求目录授权与 Git 查询。大内容采用有界预览，自动刷新、IDE 打开及目录清理后的历史阅读不在首期范围。
