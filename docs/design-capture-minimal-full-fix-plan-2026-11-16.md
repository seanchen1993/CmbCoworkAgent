# 浏览器抓取最小完整修复方案

日期：2026-11-16。状态：已实现，并完成类型检查、生产构建及真实浏览器验收。

目标：覆盖大页面卡顿、iframe 内容丢失、HTML 导入代码外露。沿用当前静态快照和本地产物模型，复用 parse5、现有浏览器 frame 访问能力、资源本地化和 ZIP 导出。

## 1. HTML 加工只修改真实节点

修改 DesignView 的 ensureEditMode / appendEditScript / injectColorVars，并统一相关宿主脚本的插入方式。

- 用 parse5 定位真实 head、body、style 和脚本节点；按源码范围编辑，最后一次拼接。
- CSS 变量和颜色只从真实 style 节点、style 属性提取。打印模板、JS 字符串、注释中出现的 HTML 不参与加工。
- 宿主脚本插入真实 body 的结束位置；没有显式结束标签时，使用解析器确定的文档结构处理。
- 统一处理宿主脚本内的结束标签转义，添加宿主标记保证重复准备幂等。
- 统一检查 materializeTweaks、installSnapshotRuntime 等结束标签正则插入点，避免另一个入口继续破坏 HTML。

建议新增一个共享的宿主节点插入/源码片段拼接辅助模块。已有脚本不作业务语义修复；原文件已损坏时返回明确诊断。

## 2. 去掉大页面的同步平方级加工

- decorateDesignNodes 保留现有 ID 算法、节点过滤及偏移，改为收集原文片段与插入片段，一次 join。
- 将预览需要的 parse5 节点装饰放到 renderer Web Worker，调用方 await；旧任务用会话及源版本校验丢弃，取消或销毁时终止相应工作。
- 相同会话、相同源版本复用准备任务与结果，避免导入提交和会话恢复重复加工。缓存只保留当前及必要的待切换版本。
- 来源页面快照的 DOM/Shadow DOM 遍历按小批次让出事件循环，并检查取消及页面变化；保持已有总预算。

验收沿用分析时的 1千、5千、1万、2万个元素夹具，记录各步骤耗时和主线程长任务。要求消除原先约 13 秒的同步拼接，准备期间输入和取消操作可响应；不预先承诺固定提速倍数。

## 3. 预览资源按文件复用 Blob URL

修改 design-html-srcdoc 的资源解析器，返回准备结果及资源释放句柄；由预览生命周期持有。

- 本地图片、字体等二进制资源转为 Blob URL；同一资源版本只创建一份，HTML/CSS 引用短 URL。
- CSS 中的相对 URL 继续按 CSS 文件自身路径解析；资源读取限制继续沿用当前目录约束。
- 复用现有读取接口即可，读取阶段的 Base64 只解码一次，不再在每个 HTML 属性中重复展开。
- Blob URL 仅存在于运行时预览；磁盘源文件保持相对路径，导出使用磁盘产物。
- 新预览加载或局部更新确认后再释放不再引用的资源；会话关闭、失败和组件销毁均释放。仍被当前页面使用的资源不得提前撤销。
- 检查文档树总字节数、唯一资源总字节数以及最终预览文档大小；取消和超限返回可理解的错误，避免静默截断。

## 4. iframe 逐 frame 静态采集并贯通下游

在 page-capture 增加 frame 协调模块，复用 browser-service 已有的 WebFrameMain 遍历与执行方式。

- 主页面和已加载的同域、跨域、srcdoc、嵌套 iframe 分别执行同一套快照与清洗逻辑。
- 建立真实子 frame 与父 iframe DOM 节点的关联，生成本次任务的 frame 标识。重复 URL、无 name、多次重定向不能依赖 URL/name/枚举顺序猜测。
- 保留 iframe 元素的布局属性；子文档分别落盘为 frames/<id>.html，保持 CSS 和文档隔离。资源按各自 document.baseURI 解析，blob/canvas 在所属 frame 内读取。
- 各 frame 共用资源缓存与总预算；建议初值为最多 32 个 frame、嵌套深度 4、并发 2，沿用当前任务的 60 秒总截止时间。具体值经回归调整。
- 清洗仅允许本次任务生成并关联成功的本地子文档引用。来源脚本、事件处理器和任意原站 iframe.src 不直接进入离线产物。
- 预览解析器递归读取可信子文档，使用 srcdoc 或本地生成的文档 Blob 展示，并应用第 3 项资源复用机制。验证器递归检查子文档，ZIP 导出复用当前目录树打包逻辑。
- 子 frame 导航、销毁、无法读取或超限时，按该 frame 降级并返回明确原因；可获得图像时提供截图，否则保留尺寸及原因占位。主页面失败仍整体失败。

交付结果是 iframe 当前已渲染内容的离线静态还原。子文档作为独立本地 HTML 保留，供后续文件编辑；原站业务交互与跨 frame 直接编辑属于不同能力，不能用本次采集成功代替验收。

## 5. 高频 UI 更新与完整产物分离

- 滚动坐标、选择框和测量尺寸在本地更新；每帧合并且值未变化时跳过。需要恢复的滚动位置仅在空闲、切换和关闭边界保存。
- 为输入草稿、缩放等少量字段增加严格白名单的轻量 UI patch；沿用现有输入合并规则。附件、消息、批注、HTML 等继续使用原完整保存流程。
- manager 的轻量分支浅合并指定字段，不调用全量 get/clone/commit；IPC 只返回 seq 与字段变化，客户端合并已有会话。缺少基线或发生序列缺口时重新 open。
- store 增加小型 design_session_ui 覆盖表，事务内更新 UI 字段和会话 seq，避免每次输入重新序列化正式 HTML。加载时合并；完整保存吸收并清理覆盖值；删除会话同步清理。
- 订阅广播与调用回复继续按 seq 去重。切换、关闭和发送前 flush 待保存 UI，覆盖表与正式保存的竞争需验证。

该表只保存严格白名单的小字段；已有会话无需重写 HTML 或历史消息。

## 最小验收集

| 范围 | 必须验证 |
| --- | --- |
| HTML 结构 | 打印模板含 body/html/style 标签、注释含标签、中文、缺省结束标签、重复准备；不出现新增代码正文，合法业务脚本仍执行 |
| 大页面 | 2万个元素；编辑 ID 与旧规则一致；输入/取消可响应；同源版本只准备一次 |
| 资源 | 同一图片引用100次只读取/注册一次；CSS背景和字体正常；切换后释放；导出无 Blob URL |
| iframe | 同域、跨域、srcdoc、嵌套、同URL多实例；相对CSS/图片/blob；断网重开仍显示子页面 |
| 异常 frame | 导航、销毁、超时、预算超限；原因提示正确且其他已成功 frame 保留 |
| UI 保存 | 滚动过程无全量产物传输；输入patch不包含HTML；切换与重启保留草稿；并发完成保存不覆盖新值 |
| 现有功能 | Tweaks、直接编辑、撤销/重做、预览更新、会话恢复、URL导入、HTML导入、完整资源包导出 |

实施顺序：先完成 1、2，解除结构损坏和主要阻塞；再完成 3、5，控制持续开销；最后接通 4 的采集、资源、预览、验证、导出。全部验收后交付，不能只修改 iframe 抓取函数就视为完整修复。


## 实施记录

五项修复已落地：

- 新增 design-html-mutations 与 design-legacy-edit-mode，宿主脚本、颜色提取和旧版 Tweaks 声明均按真实节点或 JS AST 处理；打印模板不会成为脚本插入位置。损坏的普通 JS 返回明确导入错误。
- 节点标记和源码修改统一一次拼接。renderer 使用独立 Worker，预览版本共享准备任务，取消后终止 Worker；来源 DOM/Shadow DOM 遍历分批让出事件循环。
- 正式预览与草稿预览各自管理 Blob 资源；同文件跨父子页面复用，实际加载/应用确认后释放旧版本，并保留尚待切换的最新版本。后续生成、回滚、旧版微调和需求同步读取持久源码，避免写回 Blob URL。
- frame-capture 通过 WindowProxy 身份握手关联实际父元素，分别采集同域、跨域、srcdoc 和嵌套子文档，保存为 frames/*.html。资源缓存与预算全树共享，离线验证递归检查子页面。可见但超出节点预算的子页通过截图降级。
- 新增白名单 UI patch 和 design_session_ui 覆盖表；输入/缩放等小字段不携带正式 HTML，滚动与测量在本地合并。完整保存、重启及后台生成完成均保留最新 UI 值。

可重复执行：

```sh
npm run typecheck
npm run build
npm run test:design-capture-fixes
npm run test:design-html
```

未安装 Playwright 浏览器时，可以通过 CHROMIUM_EXECUTABLE_PATH 指定本机 Chrome。Electron 回归使用独立临时用户目录和本地测试站点。

验收包含：100 次重复图片引用只读取一份资源；2 万个元素仍可输入/取消；延迟读取不泄漏资源；旧页面回执不撤销新资源；同 URL 多实例不串页；跨域/srcdoc/嵌套 iframe 及其 blob 图片离线重开正常；超预算子页截图降级；完整 React 设计流程的 Tweaks、直接编辑、输入法、撤销重做、后台恢复和需求同步。

原有 test:design-html 中存在已失效的 buildStaticHtmlPreviewDocument 引用，已对齐当前 buildHtmlPreviewDocument 接口及其网络隔离 CSP；既有 Design 资源和交互断言继续执行。

性能数字为合成夹具结果：2 万个 div、每项约 100 个汉字，Worker 准备约 0.5 秒，期间主界面计时器持续响应。它不能代替用户现场页面的端到端性能记录。

历史快照缺失的 iframe 内容及已损坏 HTML，需要使用更新后的版本重新抓取或重新导入原文件。iframe 交付仍为静态还原；原站业务运行时不会随快照迁移。
