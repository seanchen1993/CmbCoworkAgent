## 本版本的使用范围

1. 导入自己的插件组件，检查版本与用途，授权、设置、启用、更新和停用。
2. 将不同插件的组件和已有模型组合，保存自己的 Claw，并应用到普通本地对话。
3. 普通聊天在组件已接通的环节采用该组合；显式选择执行流程才运行整条步骤。
4. 自行调整开发、代码检视、真实测试和失败修复的步骤，看到各步结果、审批和取消。
5. 保留原 Plugin 项目模式、Harness、IM、Goal 及普通聊天；没有把已应用 DIY 组合
   宣称为自动覆盖 IM、协调和其他未接通入口。
6. 提供清楚的中文上手、现成示例及功能范围。保存、应用和执行各有明确说明。

声音、组件主动连接新服务及其他高级接口属于后续范围。原配置好的 MCP 工具调用
仍在主版本内，不能因收口附加接口损坏流程中的实际工具。
