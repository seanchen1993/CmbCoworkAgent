## 与本工程不同的选择

- 不直接照搬全会话权限继承；开发代码实际 SDK 调用需经过当前版本的能力范围检查。
- 不让开发试用进入全局插件安装表，也不改其他会话的 Claw。
- 自动切换前校验失败可保持旧版；退休后失败必须显示停止/未知，不能假称外部副作用已回滚。
- 原 Plugin 保留，生成纯 Function 适配包与来源报告；不把混合包塞进仅支持纯 Function 的安装器。
- 动态行为与 UI 用真实聊天场景验证；现有受限 Flow PASS 不能证明新界面接点或热重载正确。
