# 桌面复制、选中内容与侧栏状态

接在输入规则和建议之后。用户不需要学一套新页面：选中聊天里的文字，在组件按钮或命令中使用；组件可以把处理后的结果复制到剪贴板，也能知道自己的面板是否正在显示。

依据：Claude Code 2.1.288 内置类型声明的 `ui.copy`、`ui.selection`、`ui.panes`，以及官方接口说明。沿用官方接口名称，实际显示方式用 DevClaw 的聊天和右侧栏。

## 实施边界

- 三个接口都走自己的 operation 处理链；处理函数使用 `{ value }` / `{ deny }`，SDK 分别得到复制结果、选择或 `undefined`、面板数组。调用时只跳过当前处理函数，同一组件其他处理函数仍参与。
- `ui.copy` 的文字和 surface 都允许处理函数改写，core 使用最后收到的 surface。私有窗口/聊天所有者不变；改到该原会话没有实际挂载的 surface 返回 `no-surface`。
- `$.ui.copy({ text, surface? })` 默认桌面表面，经 `ui.copy` 链处理后复制。处理函数可以修改文字或拒绝。发布前执行内容保护；真正调用剪贴板前复核当前组件批准、运行作用域、原任务绑定、真实窗口和当前聊天所有者。没有当前界面返回 `no-surface`，无法写剪贴板返回 `no-clipboard`，处理函数拒绝返回 `refused`。不能把处理函数的成功声明当作实际复制成功。
- 复制捕获在处理链开始前，固定实际桌面所有者；不允许等待后迁移到新会话或新窗口。取消、撤权和窗口关闭结束在途请求。每次调用的真实完成证明独立，嵌套调用不得借用兄弟调用证明。实际剪贴板写入之后发生取消无法撤回写入，只能阻止后续发布；文档如实说明。
- `$.ui.selection()` 只返回当前聊天区域内用户亲自选中的文字。保留最近一次选择，使点按钮或输入命令后仍可用；新选择替换，Escape、下一次提示或命令实际结束、切会话及关闭清除。命令执行前不清除，否则组件读不到刚选中的内容。完成时只清除自己的旧选择，不能清除用户在等待期间的新选择。
- 选中内容不读取剪贴板、不访问其他应用或设置页。文字进入组件之前经过内容保护。单条聊天消息内的选择提供该消息实际 `requestId`；跨消息或输入框、面板的选择不伪造消息编号。DOM 的所有者、版本、授权及绘制证明保持私有，不进入组件数据。
- `$.ui.panes()` 仅列调用组件自己的已打开面板，按已放置优先、再按打开顺序返回。返回官方字段 `id/title/isShown/isFocused/isPlaced`，不提供另一组件的内部树或回调。桌面多个面板可以同时显示；状态来自当前挂载区域的实际绘制回执，未绘制及隐藏的面板不得标为已显示。接口仍执行自己的 `ui.panes` 处理链；core 只查纯元数据，不调用会重绘的 `snapshot()`、不触发 `ui.render` 或 `session.start`。
- 沿用现有 UI 所有者和 generation 机制；复制与选择使用单独桌面请求代理，避免扩大输入编辑事件。回执严格匹配原 sender、thread、owner、request，且不信任组件可修改的权限字段。
- 新能力进入 Function Mods 批准摘要并提升宿主版本。传统 Plugin、项目模式、Harness、模型选择和消息发送的处理规则保持兼容。

## 验收

真实 QuickJS：多插件改写、拒绝、伪造成功、自己跳过、嵌套兄弟调用、保护后文字、取消/撤权、旧绑定替换。

真实浏览器与 Electron：选中一条消息后点组件按钮，实际剪贴板等于处理后的选中文字；跨消息不冒充编号；选择清除/新选择保留；侧栏显示、折叠、切会话、关闭、重绘 generation 失效；无界面明确拒绝。复制测试先保存并在结束时恢复原剪贴板，不把本机原剪贴板写入测试日志。

性能检查：没有使用这些接口时不轮询剪贴板或选择、不创建新后台实例；面板查询只读取当前 DOM 状态和宿主元数据，不触发重绘；选择监听只在实际界面启用。
