# 制作、真实试用与版本恢复

日常使用路径是：普通模式描述需求 → **发送消息** → 在原任务卡或 **任务进展 → 当前任务 / 结果** 查看进展与成果。
制作路径是：创造者模式描述创建、修改或组合需求 → **发送消息** → 核对效果、用途和当前目标 → 确认试用 → 读取实际结果 → 保存使用。
制作聊天、源码草稿库和正式插件库各自保留版本；保存草稿不会安装或替你授权。

## 选择合适的验证方式

| 方式 | 实际做什么 | 还不能说明什么 |
| --- | --- | --- |
| 代码检查 | 编译、类型和当前 SDK 的静态可行性检查 | 没有执行网络、文件、模型或任务 |
| 独立样例预览 | 在一次性隔离运行中实际调用选定处理程序，显示只读结果；结束时清理运行 | 不访问项目数据，不验证真实外部服务，不保留可交互句柄 |
| 本地会话试用 | 用户批准后，在当前聊天显示界面、指令及隔离设置 | 不代表外部能力已验证 |
| 需授权的真实试用 | 核对精确源码、当前聊天与项目、用途和权限后，允许生效版本执行已获准动作 | 批准、生效和安装都不是业务结果；实际文件、网络、模型等仍经过原有权限 |

需要实时数据时可以直接申请真实试用，无需先安装再反复转正。不要用固定文字、动画或模型的说明
冒充实际调用。执行后读取文件或业务能力的 `read/status`，核对真实结果和版本来源。

## 在制作聊天确认

1. 打开关联本地目录的聊天，在输入框旁选择 **创造者模式**，直接描述用途、目标与期望效果，点击 **发送消息**。
2. 助手保存真实源码、检查后请求试用。打开 **确认灵件试用**，核对用途、当前目标和权限。
   完整能力名称与源码摘要在 **制作详情与完整权限** 中。
3. 点击 **确认并应用到这段聊天**。批准绑定当前源码摘要和编译摘要；
   版本或目标变化后旧确认不能用于新请求。
4. 等待本轮制作与现有任务安全结束。版本生效后，再按使用说明触发命令或页面动作。
5. 实际动作如需文件或工具权限，仍处理原有批准提示。随后读取真实状态核对效果，再保存使用。

切换到 **普通模式** 会收起创作能力，已生效的 Mods 继续使用。停止试用与切换模式分别处理，
避免回到日常任务时丢失刚制作的功能。手工编辑、组合和流程管理保留在高级自定义入口。

同一聊天的源码会保留；重启后点击 **恢复这个灵件**，核对当前状态并重新确认恢复运行。
正式复用时，点击 **保存并在其他聊天复用…**，核对当前版本和项目权限，再点击 **确认保存并复用**。
这会安装、授予当前项目权限、保存组合并加入当前聊天；使用默认继承设置的其他聊天也会包含本项目已授权的功能。
保存不会发送消息或执行任务，详细范围见[安装与复用](reuse.md)。

| 面板状态 | 下一步 |
| --- | --- |
| 待确认 | 核对用途、目标和新增权限，再决定是否试用 |
| 排队 | 等待制作轮和当前任务结束；中断的制作先回聊天继续 |
| 检查新版本／停止旧版本 | 等待检查和清理，不重复启动 |
| 版本已生效，真实结果待核对 | 触发所需动作，再读取实际结果 |
| 新版本失败 | 准备阶段失败保留旧可用版；点“修复并重新检查”直接提交修复新版本 |
| 结果待核对 | 先读实际状态，保留记录；未知操作不自动重试或重放 |
| 已停止 | 运行已停止；继续制作需重新申请，不沿用停止前的试用授权 |

## 修改、升级和回退

同一聊天内，已批准范围内的源码更新可以排队应用；新增权限必须再次确认。成功版本删掉的权限
会收回，再加入时需要重新确认。等待新版期间旧版仍受它自己的权限范围约束，不能使用新版新增能力。

候选检查不执行外部副作用。不要在 `session.start` 写文件、联网或启动持续任务；这里用于登记命令
和无副作用界面。把真实动作放在生效后由用户触发的命令或业务动作中。

候选检查失败时旧可用版保留。如果旧版已经停止而清理或切换结果无法确认，显示未知状态并阻止继续
自动切换。先核对真实资源和结果；恢复源码不会重新执行以前的写入、调用或任务。

正式保存和安装继续使用原来的版本检查与授权。更新 SDK 或插件代码会改变编译摘要；旧版本授权
不能静默获得新增接口。本次平台 SDK 的宿主版本是 v91，旧摘要需要按现有提示重新确认。
安装结果不确定时，使用实际安装状态核对和既有版本恢复入口，不反复点击安装来猜测结果。

## 配置目标和草稿

在设置页顶部选择 **为哪段聊天配置**，再编辑参数。参数面板显示实际项目目标与所选聊天的应用状态。
通用参数在同一项目中共享；功能组合和这段聊天实际启用的版本仍分别核对。

切换配置对象时，未保存的编辑先提示保存或确认放弃；正在保存、选择路径或应用时不切换目标。
保存不等于当前任务立即换用：进行中的任务保留原设置，安全空闲后应用。应用失败时保留草稿并查看
原因；密钥不回显。代码或配置版本变化、撤权及迟到回复不能覆盖新目标的编辑。

## 持续任务与资源

关闭制作面板不会停止已生效任务。**停止此组件试用**、结束创作、撤权、停用、删除来源或退出应用
会撤销当前运行入口，清理所属订阅、页面、计时器、调用和后台资源；清理未确认时保留未知状态。
切换聊天只改变可见目标，不将旧聊天的状态或事件交给新聊天。

普通计时器依赖应用进程，退出后不运行。重启只恢复可核对的记录，不恢复试用授权、不自动重新启动
任务，也不重放结果未知的动作。确需持续任务时，作者应声明退出语义，使用可取消动作和有界状态，
恢复前读取实际状态并重新检查权限。

技术详情中的宿主诊断显示当前聊天组合的实际计数，包含同一运行中的既有灵件；缺少观察证明时写“未知”，
不能把未知计数当作零。注册页面或业务能力不授予调用权限，消费另一灵件也不会继承提供方的全部权限。

## 作者最小清单

- 从当前构建的作者目录读取声明，使用受支持的 SDK 和稳定协议版本；不要调用原生 IPC。
- `on.capability` 声明业务能力和动作的输入、输出、权限、取消及重复请求语义；状态与动作分开。
- 页面和行为声明复用同一能力协议。页面打开、替换应用和任务启动分别由用户明确操作。
- 用已有文件／模型／网络权限执行真实任务；不要另建 Agent 主循环或凭据存储。
- 返回真实读取结果；有副作用的未知结果先检查，不自行换请求编号来再次执行。
- 为失败、取消、升级、旧版本迟到、撤权、删除及重启添加回归；保留第一轮失败证据。

[个人任务工作台](../../examples/sparks-task-workbench/README.md)的提供与消费包演示了跨包组合。
它证明已接入的平台能力；不代表所有业务模块已经开放，也不替代持续观察、完整回归或实际业务验收。
