# AutoBiz 项目组合示例

这套示例让你在一个项目里，先运行 AutoBiz，再起草并审核项目文档。

## 安装两份插件

打开 DevClaw 的 **自定义助手**，在“我已添加”区域点 **上传插件（ZIP）**，依次选择：

1. `autobiz-project-composition-demo.zip`：AutoBiz 完整流程示例。
2. `project-docs-composition-demo.zip`：基于 `project-docs-lite` 0.2.0 的文档编写与审核示例。

安装后启用两个插件。它们使用独立名称，不会替换你原来的 AutoBiz 或文档插件。
也可用 **从文件夹安装**，选择同名文件夹；不要选择包含两份 ZIP 的外层交付目录。

## 准备一个项目

使用 Windows，先确认电脑上的 `python` 命令可用，并在 DevClaw 中选好可用模型。
建议在新的空工作目录里练习，模型调用按你自己的模型配置计费。

已有项目：打开 **项目模式**，进入项目对话即可。

新项目：在 **项目模式** 点击 **新建项目**，可按下面填写：

| 页面上的字段 | 本地练习示例 |
| --- | --- |
| 项目编号 | `LOCALDEMO` |
| 项目名称 | 本地订单导出演示 |
| 系统编号 | `LOCAL` |
| 系统名称 | 本地练习 |
| 插件 | `autobiz-project-composition-demo` |
| 插件工作区根目录 | 点击输入框，选择一个新的空文件夹 |
| 本项目产物文件夹 | `order-export-demo` |
| 项目描述 | 可不填，也可写“本地练习订单导出” |

页面会显示最终产物目录，确认后点击 **创建**。项目编号检查结束后才能提交；本地练习无需关联真实企业项目。创建成功后进入该项目的对话。

## 组合并执行

1. 进入项目对话，点击标题栏的 **项目能力**。
2. 在 **按顺序执行 · 完整流程** 中，先添加 **AutoBiz 示例完整流程**，再添加 **起草并审核需求文档**。
   在文档流程的“前序已检查资料与源码变更”中选择 AutoBiz 的 `verified-context`。
   未提供这一出口的旧副本需要新建组合副本并安装新版本，已冻结的旧运行不会自动补交资料。
3. 在 **这次要做什么** 中填写共同目标。例如：

   > 为一个本地订单列表增加 CSV 导出功能：按日期筛选，包含订单号、金额和状态，没有数据时显示提示。按这些需求编写操作说明，并检查操作步骤、字段解释和异常提示是否完整。本次不连接企业系统、不部署、不提交或推送代码。

4. 点击 **检查并预览组合**，确认顺序与任务，再点 **确认并启动**。
5. 在 **运行过程** 查看进度。原流程需要你补充需求或批准操作时，先处理提示。AutoBiz 的原检查和审批仍然有效；它成功后文档流程才开始，失败时后续流程不会执行。

## 查看结果

- AutoBiz 步骤：点 **查看结果**，核对 `verified-context` 中的真实正文、原路径、SHA256 和检查来源；也可打开运行文件夹。
- 文档步骤：点 **查看结果**，阅读文档草稿 `draft.md` 和审核结果 `review.json`。
- 遇到失败：先看原因和已有文件，按提示处理后核对恢复；不要反复启动整套任务。

两套流程使用各自的运行目录。显式选择资料后，宿主只交接原流程已声明且通过检查、终态仍与检查哈希一致的业务、设计和报告文件，正文包含在固定资料包中。文档流程必须实际读取资料并记录引用的路径与摘要。
新适配副本还显式声明 `devclaw.source-handoff.json`：示例将本次源码写入 `src`。宿主在原初始化和需求创建完成、模型启动前冻结该范围的文件路径与哈希，结束后交接范围内新增/修改的实际源码正文与 SHA256、删除记录及基线摘要。`project-docs-lite` 0.2.0 的起草和复核阶段都必须实际读取映射后的 `inputs/verified-context.json`，使用 `files` 的原检查资料和 `sourceChanges` 的源码正文，并记录引用的路径、摘要及基线范围。
源码差异是宿主观察的字节证据，原流程的检查与审批仍须完成；它不代表范围外源码、逐文件或独立业务质量验收。没有映射资料时，只能按共同任务起草，并明确说明没有使用前序成果。
资料包最多 128 个文件、256 KiB，只支持完整 UTF-8 文本；超限、未知证据或文件被改写会阻止交接及后续启动，不能用截断正文或任务文字替代。

如只想辅助当前项目对话，在 **对话中使用** 勾选文档插件的 **整理项目需求**，点 **预览对话能力 → 确认应用对话能力**，再回到项目对话描述需求即可。

## 示例范围

AutoBiz 来自已验证的固定版本，原技能、Python 脚本、Hooks 和阶段检查保留。本示例关闭了原企业 MCP 连接配置；需要企业查询、专用 TestAgent 或其他外部服务的任务，仍需对应环境，不能用本地示例代替。

ZIP 是完整安装包，已包含组合配置，无需手写“公开动作”或再创建副本。它不包含现成的业务成果，运行时仍需模型执行、原检查和你的确认。更新原 AutoBiz 不会自动更新本示例。

`package-manifest.json` 记录源码版本、文件差异和安装包校验值；`acceptance.json` 记录交付包的实际验证结果。
