## 这一步给用户带来什么

插件可以把提醒保存到当前会话，例如“编码结束后按团队清单检查”。保存提醒本身不
启动模型；下一次正常继续任务时，系统把提醒放在新提问之前，保存后不会重复加入。
插件也可以保存普通通知，例如“检查清单已更新”，通知只显示，不当作用户指令。

这使得不同组件能够围绕同一个任务配合，减少手动复制提示词。此前的插件工具、
项目模式和 Harness 仍须独立回检，不能因为新接口测试通过就推断旧功能均无影响。

## 已经接入的实际路径

- 插件实际实例的追加与读取入口，包括按钮、定时器和原模型来源的检查。
- 会话数据库与聊天记录同一次保存，返回成功前核对实际保存结果。
- 正常图输入中的提醒接纳，连同接纳进度写入原来的 checkpoint。
- 完整原生消息保存格式，保留工具结果的真实角色、工具编号与附加内容。
- 旧消息转换、显示和恢复入口对新记录的识别，损坏记录不当作旧消息猜测。
- 已保存通知的即时显示接线；真实 Electron 已验证保存后在原页面立即出现。
- 插件实例结束后的普通任务路径调整，避免普通聊天依赖已经退出的插件。

上面的接线并不代表下面尚在实施的端到端路径已经验收。
