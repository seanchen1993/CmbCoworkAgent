# Mods 交互与内置说明

开发目录：`C:\ai\CmbCoworkAgent-mods-v2`，分支：`codex/mods-v2`。

## 从哪里开始

打开“自定义 → Function Mods”。顶部是“打造你的 Claw”和可展开的“使用指南”，
设置和指南均可直接使用，无需管理口令。指南分为快速上手、Autobiz 实战和常见问题。

1. 安装示范 Mods，或导入自己的插件文件夹 / ZIP。
2. 开启应用级开关，为当前会话选择项目目录，再开启项目 Mods。
3. 核对插件能力，在对应卡片授权当前版本。
4. 回到聊天框使用命令，或点击“去编排流程”。

上手进度根据实际读取状态提示下一步。配置读取失败时显示明确错误和“重新读取”，
重试只读取状态，不重新执行安装、授权等操作。

## 内置体验说明

- 内置示范授权后可复制 `/claw-info`、`/claw-files`。
- Autobiz 页签说明如何导入 `examples/mods-review-agent`、选择简短或严格检视角色、
  查看 `/claw-review-status`。它明确区分角色与模型，也说明需准备真实 Git 差异。
- 复制仅写入剪贴板；需用户在聊天框粘贴并发送。复制失败或系统未提供接口时显示手动复制提示。
- DIY 流程页面提供“如何搭建自己的流程”，说明选择步骤、排序、分支、保存版本、
  执行记录和人工确认。草稿中停用的步骤标记为“已停用”。

## 界面处理

采用统一宽度、分区卡片、主题色状态、适度留白及折叠说明。完整权限与版本信息仍可展开核对。
原有授权、安装、卸载、运行门槛保持原逻辑；历史记录的读取方式未变。

亮色、暗色和 420px 窄窗口有浏览器截图验证。指南页签使用现有可访问 Tabs，
复制按钮有具体标签，复制结果及步骤提示可被辅助技术读取。
