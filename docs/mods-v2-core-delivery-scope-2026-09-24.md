# Mods v2 核心交付范围

2026-09-24 用户调整：先保证主要功能和现有应用正常使用；实现复杂、收益较低的边界兼容功能可以延期。此页调整后续优先级，不把缺失能力改写为已完成，也不取消权限、证据和状态推进的正确性要求。

## 本轮必须收尾

- 插件安装、摘要授权、隔离 guest/session、命令和工具；取消、撤权、runtime 替换与关闭恢复原生行为。
- 原 Agent 模型/完成循环、宿主检查证据、修改后失效、预算、项目 DIY 配置及过程解释。
- 已开放的桌面 Pane/Client 和站点保持可用，修复已确认的资源残留和存量回归。
- 保留真实 Autobiz 修复复检与 validator/checkpoint 演示的证据及适用范围。
- 完成核心回归和最终代码检视，提供准确的使用说明与兼容差异；安装包继续由 GitHub Actions 构建。

当前这些主链路已有实现及真实 Electron 验证；不代表最终性能、长稳或安装包验收已经通过。结果以[实施状态](mods-v2-status-2026-09-24.md)和各次报告为准。

## 延期的兼容边界

| 范围 | 本轮处理 |
| --- | --- |
| 仅 schema/手动分发的 15 个 classic 事件 | 保留 partial/metadata 和生产未接线说明；不为补齐事件名建立另一套任务、权限或工作区生命周期。 |
| audio、http、process、env/settings、agent.spawn、fs.ancestors、独立 clock 定时器等未开放 SDK | 保持 unavailable；现有受控工具不冒称这些 SDK 的等价实现。 |
| 尚未提供的浏览器全局对象、二进制文件读取 | 暂不扩展；已实现的 Base64 和文本读取继续验证。不以 UTF-8 文本代替 bytes。 |
| 非桌面 surface、所有 UI site 的完整 Client/焦点/滚动等价性 | 暂不扩展；先保证已声明的桌面子集稳定。 |
| 未知 checkpoint 提交的自动回滚/重放、整个工作区原子事务 | 保持保守恢复边界和只读核对；不能把未知状态变成 PASS，也不能自动重复推进。 |

完整逐项状态仍见[兼容矩阵](mods-v2-compatibility-matrix.json)。延期不是兼容验收通过，后续扩展仍须先失败测试、真实 guest/session 和 Electron 验证。

## 验证边界

短测只用于检查测试链路和明显回归，不替代正式性能或两小时长稳。此前 ingress 超预算、长稳 ACK 超时及中断运行的原始记录继续保留。收尾时将功能结果、性能结果和安装包结果分别报告，不能因缩小实现范围而删除失败或放宽判定。
