# 项目模式体验优化清单

更新时间：2026-08-27 11:26:36（GMT+8）

## 项目会话清理

- [x] 已删除项目支持删除项目下的全部会话。
- [x] 已删除项目支持删除单个特性组下的全部会话。
- [x] 正常和已归档项目支持删除项目下的全部会话，并保留项目实体及状态。
- [x] 正常和已归档特性组支持删除组内全部会话，并保留特性实体。
- [x] 正常和已归档特性组同时保留新增会话入口。
- [x] 删除确认、运行态禁用和串行删除行为与对话模式保持一致。
- [x] 共享删除内核与确认弹窗，模式特有的分组和选中态各自维护。
- [x] 仅检查修改文件，并通过 Web 类型检查；不运行生产构建。

## 新建项目插件排序

- [x] 插件下拉优先展示“已安装插件”，随后展示“更多插件”。
- [x] 两个区域内部继续复用现有使用场景分组与排序规则。
- [x] 已安装但不兼容的插件仍归入已安装区域，并保留禁用与兼容性提示。

## 插件运行产物

- [x] 项目模式的特性会话在“文件”下方展示“插件运行产物”折叠页。
- [x] 仅展示 `feature_status` 返回且状态为 `generated` 的 `path/paths`。
- [x] 复用现有文件预览事件，点击文件后切换到“文件预览”。
- [x] 产物列表更新使用 3 秒防抖，不改变现有 `watchRefs` 刷新时效。
- [x] Feature 和会话归属立即更新，仅文件路径列表参与 3 秒防抖。
- [x] 同一特性的会话共享产物列表；项目删除后不再展示。
