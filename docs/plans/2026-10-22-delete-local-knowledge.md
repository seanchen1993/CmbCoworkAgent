# 删除本地知识库

用户在公共系统约束卡片上确认删除后，删除该库的 read、write 目录和 knowledge-state.json 中对应记录，保留项目绑定和其他知识库。

1. 主进程复用现有同步忙碌状态与沉淀会话占用判断。刷新或同步期间不删除；删除期间暂停启动新的刷新、同步和该库沉淀，不排队。
2. 使用 knowledgeDirectory 校验 idKey 后删除两个目录；目录不存在也可清理记录，文件操作失败保留状态记录并提示错误。
3. 增加 IPC 与 preload 方法。卡片增加删除按钮和确认对话框，明确本地未提交改动也会删除、项目绑定保留，云端仍下发时下次刷新会重新下载。
4. 使用现有会话运行信息验证活跃沉淀任务阻止删除，停止后可删除；补充删除成功、目录缺失、操作失败、同步忙碌、无效 id 和云端恢复测试。
5. 运行相关单元测试、主进程及界面类型检查，仅检查修改文件 lint，不使用浏览器或截图验证。
