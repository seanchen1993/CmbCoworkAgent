## 最小改动

新增测试专用启动助手，四组检查只替换启动选项并允许独立结果目录。
只有显式指定 `CMB_MODS_PACKAGED_DIR` 才启动指定包；没有指定时仍启动
原 `out/main/index.js`。错误路径或空值必须拒绝，不能退回普通构建。
包模式将二进制和 `CMB_MODS_E2E=0` 放进原隔离环境的副本，不继承主机凭据。

原 `electron-launcher.cmd`、业务源码、完整 39 项断言、审批、固定模型服务、
每步时间限制、关闭与重启顺序不变。流程和旧 Plugin 重启后继续使用同一个包和
同一个测试数据目录。每次真实启动检查应用处于打包状态、程序与 ASAR 路径正确、
包中没有测试专用入口，并保存启动记录。检查前后核对包文件摘要。

四组检查使用新的独立结果目录，不覆盖上轮普通构建的通过或失败记录。
关闭仅作用于当前测试启动的应用和服务；不用进程名称批量结束，不安装 NSIS，
不写真实用户数据和安装注册。真实 MCP、适配程序和测试命令仍使用隔离夹具与
已有宿主测试前置，不能冒充包捆绑或客户业务验收。
