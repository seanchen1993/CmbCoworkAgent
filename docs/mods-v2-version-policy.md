# Mods-v2 分支版本约定

用户确认：`codex/mods-v2` 分支的应用版本固定为 **2.0.0**。

- 后续可以继续开发、修复、测试和重新打包，不冻结功能代码。
- 功能修改、问题修复和常规构建均不得自动提升应用版本号。
- `package.json`、`package-lock.json` 顶层及根包记录的版本保持 `2.0.0`。
- 分支名称保持不变，不因版本调整创建、切换或推送其他分支。
- 不同构建通过 Git 提交 SHA、GitHub Actions 运行编号和产物摘要区分。
- 既有构建的版本、下载链接及验收记录保留真实历史，不改写为 2.0.0。

只有用户后续明确要求更改应用版本时，才调整本约定。插件自身的独立版本不随应用版本自动改写。
