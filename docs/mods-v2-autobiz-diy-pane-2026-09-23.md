# Autobiz DIY 配置面板

示例的 `/kanban` 面板使用项目级 `completion-config` 保存完整规则：

- 完成行为：关闭、仅报告、有问题则阻止完成、自动修复并复检。
- 检查范围：当前文件、当前 diff、Feature、整个项目。
- 检查组合：代码评审、单元测试、E2E、Autobiz validator；逐项按钮可同时启用多项。
- 文件路径和 Feature 独立保存。文件路径必须是项目内可读取的相对路径；Feature 从当前真实 state.json 记录中选择。
- 最大修复次数 0–10、最长时间 1,000–3,600,000 毫秒、模型 Token 总预算 256–1,000,000（输入 + 输出）。

开启状态至少保留一个检查。空选择、非法路径和越界预算不会覆盖上次保存的配置。面板展示已保存规则，真实执行与预算核算仍由宿主完成循环负责；面板不能自行放行验收或推进 checkpoint。

`completion-config` 是主记录。保存面板字段会同步兼容命令字段 `review-mode` 和 `review-target`；已有主记录不会被过期兼容字段覆盖。只有缺少主记录时才从旧字段读取旧单文件模式。配置通过宿主项目与插件命名空间持久化，重开会话时恢复。畸形持久配置会明确报错，不显示为有效规则，也不静默改写数据。

最近结果按照检查项、范围、插件报告状态、原因、涉及文件、下一步动作逐项显示。其来源为插件的 `review-result`，标注为“插件评审意见”，**不代表宿主测试验收或 checkpoint 推进**。真实 PASS、文件指纹、validator 和状态推进结果以宿主完成门禁证据为准。

为限制绘制成本，面板最多显示前 24 项步骤、每项前 12 个文件，摘要与文本字段有长度限制；超过步骤数量会提示查看宿主完整记录。文本移除终端控制字符，由受限 UI 组件显示，不接受任意 HTML。

本轮独立测试使用真实 QuickJS guest、FunctionSession 的 Pane 动作路由、ProjectFunctionFiles 和实际 SQLite FunctionStateStore，验证字段保存、检查组合、关闭重开数据库后的恢复、错误配置保护及证据展示。它们证明配置面板的行为；真实模型预算、原完成循环修复、validator 和 Electron 交互仍需各自的集成证据，不能由这些面板测试替代。
