# 项目插件 ZIP 导入与原项目入口修复（2026-11-02）

本次修复平台的列表投影与项目入口，保留原有项目创建、配置、特性和运行流程。
应用版本继续为 2.0.0，代码只提交和推送到 `codex/mods-v2` 开发分支。

## 修复内容

1. **上传一个项目包后出现多个主插件。** 旧的完整列表接口已带项目依赖关系，
   实际界面使用的分页 Worker 接口却缺少这部分信息。现在由分页目录在完整安装身份集合上
   读取并验证项目清单、动作锁和主插件身份，再投影依赖关系。界面默认显示一个项目主插件，
   三个实现组件保留在可展开的“依赖组件”中。独立插件仍独立显示。
2. **项目首页出现 `PROJECT_PLUGIN_UNAVAILABLE`。** 一个绑定插件已被移除的历史项目，
   会使整批项目详情读取失败。现在只将该项目转换为中文警告，其他项目继续正常加载。
   保持原安装身份绑定，不按名称替换插件，不扩大对未知错误的捕获范围。
3. **首次“去使用”时两个弹窗叠加。** 项目入口在同一次挂载中关闭指南并打开原表单，
   指南此前尚未订阅关闭事件，晚到的读取会再次打开指南。现在在 layout 阶段订阅，
   保留原清理、取消和异步保护，不记忆全局关闭、不自动确认、不改变展示预算。
4. 校正项目入门指南中的陈旧阶段页文案，使用现有“项目信息”“新建特性”路径。

上述逻辑没有 AutoBiz 名称判断、业务阶段判断或专属权限规则。读取仍受原文件数、总字节、
快照、分页响应和取消预算约束，依赖分组只是展示信息，不授予执行权限。
