# 桌面 Svg 组件

Pane 的 `$.ui.resolve(e).Svg` 和 Client 的 `surface.elements.Svg` 现在接受
`source`、必填 `alt`、可选数字 `width/height`（CSS像素）和 `isInteractive`。
`source` 上限与固定官方声明相同：131072字符，整个树仍受1MiB传输预算约束。

静态图使用 SVG 图像；交互图使用不允许脚本、同源访问或导航权限的 sandbox iframe。
两种方式都先在脱离页面的 XML 文档中筛选节点和属性，源码不进入应用 DOM。
交互图另有 CSP 禁止脚本、网络资源、表单和 base URL；允许局部CSS与悬停。
不合法XML、DTD、实体声明、超过2000节点或32层的图形显示替代文字。

```tsx
const { Svg } = $.ui.resolve(e)
return <Svg source={'<svg xmlns="http://www.w3.org/2000/svg"><circle cx="20" cy="20" r="10"/></svg>'}
  alt="状态圆点" width={40} height={40} isInteractive />
```

兼容状态为 `adapted`。支持常见形状、文字、渐变、局部use引用、CSS hover和title；
禁止脚本、事件属性、链接、外部资源、foreignObject、SMIL与滤镜。
交互图省略尺寸时采用iframe默认尺寸，建议显式指定；未宣称任意SVG或其他终端surface兼容。
关闭、撤权和组件卸载会随原Pane/Client生命周期移除图像与iframe。
宿主修订v38需要重新批准插件摘要。
