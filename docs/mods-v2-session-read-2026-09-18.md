基线 `052f11c5`，开发分支 `codex/mods-v2`，宿主修订 `desktop-session-read-v19`。
目标仍为冻结的 Claude Code 2.1.273。没有新增依赖或数据库迁移；宿主修订变化需要重新批准插件摘要。

## 用户可见效果

`/claw-session` 显示会话、工作目录、主模型、用户轮次、消息数量、最近回复和 Git 仓库。
第一次普通消息之前也可查询；命令本身不会调用模型。`session.messages/model/turns/repo/authorize`
均走普通操作事件链和输出保护，可以被插件观察、改写或拒绝。普通操作的 `{ deny }` 是可组合的返回值；
变换下游结果的插件应显式传递拒绝。宿主权限拒绝和输出保护仍在插件链外强制执行。

## 对照依据与实现

冻结产物 `chunk-hr43png0.js` 的 `Phn/aO/lO/Iw` 把会话视图绑定到主会话，
`Let` 读取主模型，`Oyn/ZRe` 投影最近 4096 条符合条件的消息、回填工具结果，`mRo` 统计用户提示，
`pRo/FAo` 读取主工作树和 push origin，并移除 URL userinfo。公开声明对应 SessionMessage、SessionRepo。
共享子代理读取的是主会话模型和 transcript；工具目录和执行权限仍属于调用者自己的实例。

主图只在 Mods 活跃时增加状态观察器，读取真正的 beforeAgent、model/tool 边界、afterModel、
afterAgent 状态，不修改图状态、不插入虚构用户或工具消息。模型名称由实际解析的运行配置传入，
不从模型类私有字段推断。消息引用绑定到宿主私有实例，查询时投影并复制为 JSON；子代理不能覆盖主视图。
图的补答路由通过真实 createAgent 回归验证。

冷消息读取使用独立只读 Worker 操作，在 SQLite 一致性事务中遍历内联或增量检查点。
不创建运行图、模型、写入租约或检查点，不触发迁移，不回退到界面日志；路径查询也不创建目录或登记新文件。
未建立检查点与检查点损坏是不同结果。遍历保留所选消息的完整文本、工具参数和已有 artifact，
不使用 UI 读取器的截断摘要。增量链的 prefix/suffix、顺序和数量必须有效。

消息去除 system/progress、内部提示和 meta/virtual 用户消息；文本块直接连接，工具结果按时间回填。
只公开 SDK 字段，隐藏 reasoning、原始配置及内部 handle。原生 ToolMessage 以用户侧工具结果表示。
用户轮次单独遍历统计，不受消息输出总字节限制影响，也不把工具回复或界面命令记录算成提示。

Git 每次使用固定 argv 查询，不执行 shell 插值，移除 Git 环境重定向；关联 worktree 返回主工作树。
仅确认“不在仓库”和“没有 origin”时返回空；配置损坏等错误不会被伪装成无仓库。
第一方 Anthropic 授权未接入时 `session.authorize()` 返回 null，不暴露 CMB 凭据，不制造授权句柄。

## 预算、失效和验证

消息读取最多扫描 100000 条源消息，单条原始持久消息最多 1 MiB，公开结果沿用 1 MiB、节点和深度预算。
Worker 保留的候选尾部 JSON 不超过 1 MiB；若最近 4096 条所需内容无法完整容纳则报错，不静默返回残缺文本。
包含超大图片或额外字段的原始消息也可能触发原始行预算，这是本工程的资源边界，不宣称无限历史兼容。
查询绑定 workspace、调用实例、主会话实例、配置和线程元数据；关闭或替换实例会废弃在途结果。
宿主只读查询共用 100 项上限、finally 释放；Worker 请求上限 128，取消立即释放主进程请求和监听器，
通过共享取消位终止 Worker 遍历，忽略迟到响应。
长会话的内存读取每扫描 64 条让出事件循环并检查取消与实例归属；只读检查点路径使用已解析的
存储根，不调用会创建应用目录的初始化函数。Worker 启动等待后再次核验容量，防止并发请求穿透上限。
