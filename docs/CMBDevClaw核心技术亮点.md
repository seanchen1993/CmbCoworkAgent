# CMBDevClaw核心技术亮点

以下内容仅基于 Sean Chen 和 w876249494 在 CMBDevClaw UAT 分支的源码及提交记录整理，重复能力已经合并。

# 一、代码质量提升

## 1. CMBDevClaw Agent Team协作交付

**技术亮点：** 由主协调者动态拆解任务，调度多个相互隔离的Worker分别完成代码勘察、实施和复核；支持异步通知、独立Checkpoint、运行状态管理和故障恢复。

**效果：** 将复杂研发任务从单Agent串行执行升级为团队协作，通过实施与复核分离减少遗漏和误改，提升大型任务的交付速度和一次完成质量。

## 2. CMBDevClaw多领域专家团队

**技术亮点：** 内置架构设计、代码审查、问题诊断、安全检查、测试工程和文档编写等16类专家Agent，每类角色拥有独立职责、专业提示词和执行边界，并可按需启用。

**效果：** 不同研发任务可以交给对应领域的专家处理，使方案设计、代码实施和质量审查更有针对性，提升复杂问题的分析深度和交付专业度。

## 3. Compose Delivery端到端研发工作流

**技术亮点：** 基于CMBDevClaw Dynamic Workflow，将项目勘察、方案设计、任务拆解、TDD实施、工程验证、代码审查、问题修复、交付报告和代码合并自动串联；通过JSON Schema约束阶段输出，并以真实测试与构建结果、验收标准和完整代码变更作为交付依据。

**效果：** 将多阶段研发从人工接力转变为自动推进；只有通过工程验证、满足验收标准并完成关键问题修复，任务才进入合并，减少未验证代码和交付遗漏。

## 4. Agent Runtime可靠执行与会话恢复

**技术亮点：** 对模型流式输出、Tool Call、运行中消息、子Agent记录和会话Checkpoint进行统一状态管理；异常或截断的工具参数可自动修复，消息按真实运行实例排序，完整执行记录持久化后支持会话Fork和断点恢复。

**效果：** 避免异常Tool Call引发接口错误、重复调用和执行死循环，同时防止长会话中的消息丢失、重复和乱序，使多Agent任务在中断恢复和会话派生后仍能保持状态一致。

## 5. Hooks研发质量门禁

**技术亮点：** 建立覆盖模型调用、工具执行、子Agent运行和任务结束等关键节点的Hooks系统，支持命令、提示词和HTTP处理器，并具备作用域继承、异步执行、条件匹配、结果落盘和强制阻断能力。

**效果：** 代码检查、测试验证、安全扫描和团队规范可以直接嵌入Agent执行过程，使质量要求从人工提醒转变为自动触发、能够阻断不合格交付的系统规则。

# 二、研发效率提升

## 1. Ultra Workflow大型任务动态编排

**技术亮点：** 建设可编程的工作流引擎，原生支持Agent、Parallel、Pipeline和Phase等执行单元，并可通过JavaScript根据阶段结果动态生成后续任务；同时具备并发控制、结构化输出、执行日志和故障恢复能力。

**效果：** 全库审计、跨模块改造和批量代码迁移可以拆分为多个任务并行推进，流程还能根据中间结果自动调整，减少人工拆任务、盯进度和反复补充指令的成本。

## 2. Persistent Goals长任务持续执行

**技术亮点：** 将目标、完成标准、限制条件和执行证据持久化，通过Goal Manager、证据Ledger和独立Evaluator持续判断任务是否真正完成，并对后台结果、审批等待和异常中断进行恢复处理。

**效果：** 长任务不会因为单轮对话结束、上下文压缩或程序重启而丢失目标，Agent能够自动识别未完成事项并继续推进，减少用户反复催促和重新说明背景。

## 3. Plugin、Skill与MCP一体化扩展

**技术亮点：** 建立统一插件模型，将Skill、MCP工具和Hooks组合为可安装、可配置、可在线编辑的能力包，并支持嵌套Skill、作用域隔离、工具别名、版本管理和市场分发。

**效果：** 新研发能力可以通过插件快速接入，无需持续修改Agent核心代码；团队能力能够统一封装、共享和升级，避免每个项目重复配置工具、提示词和自动化规则。

## 4. LocalSandbox Windows工程执行底座

**技术亮点：** 针对Windows企业研发环境统一处理PowerShell、CMD、Git Bash、路径转义、中文编码、进程树和构建工具兼容，并增强Ripgrep搜索、大文件流式读取、非UTF-8识别和超时进程回收。

**效果：** Agent可以稳定处理Windows下的大型Java工程、中文目录和复杂构建命令，减少乱码、路径错误、Shell不兼容、命令卡死和残留进程等本地执行问题。

## 5. Memory与Dream项目知识复用

**技术亮点：** 以事实为最小单元进行类型化记忆和去重更新，结合关键词、向量与RRF融合排序完成检索；Dream对历史会话进行离线整理，并通过项目、会话和命名空间隔离知识范围。

**效果：** 项目规范、历史结论和排障经验能够跨会话持续复用，减少重复扫描代码和重复试错；知识检索更贴近当前项目，同时避免不同项目之间相互污染。

# 三、安全能力提升

## 1. Windows Sandbox分级隔离执行

**技术亮点：** 建立Unelevated与Elevated两级Windows沙箱，通过受限Token、独立账户、ACL、防火墙和进程树控制限制执行边界；配套只读命令识别、文件审批、沙箱逃逸审批、环境预热和依赖缓存，失败时坚持关闭执行而不是静默降级。

**效果：** 普通研发命令在低权限环境运行，高风险操作进入更严格的隔离层；即使Agent生成错误命令，影响也被限制在沙箱范围内，同时兼顾Maven、Python、Git等真实工程工具的可用性和执行效率。

# 四、Token成本控制

## 1. 上下文动态预算与工具输出限流

**技术亮点：** 根据模型上下文窗口动态调整摘要、工具结果驱逐和输出上限，并对Grep、Glob、目录遍历和文件读取分别设置结果数量与字符预算，结合流式读取、精确分页和超长行续读控制数据进入模型的规模。

**效果：** 大型代码仓库、构建日志和超长文件不会一次性占满上下文，Agent只读取当前推理需要的代码证据，减少上下文溢出、过早摘要和无效Token消耗。

## 2. MCP工具调用优化闭环

**技术亮点：** 将按需工具发现、延迟工具加载、必要字段投影和重复失败熔断组成完整闭环；模型只加载当前任务相关的工具，只接收需要的结果字段，相同失败调用会被自动识别和阻断。

**效果：** 避免大量MCP定义和完整返回结果反复进入上下文，也能阻止Agent在相同错误上循环调用，使工具选择更准确、失败更快收敛，并降低工具调用产生的Token成本。

## 3. Workflow内容哈希断点复用

**技术亮点：** 根据工作流脚本、Prompt、Schema、模型和输入参数生成内容哈希，将执行结果写入原子化Journal；任务恢复时，只重新执行输入发生变化或尚未完成的节点。

**效果：** 长任务中断后无需从头调用模型，已完成且输入未变化的节点可以直接复用，避免重复调用模型和重复修改代码，节省Token消耗和任务恢复时间。
