## 私有开发接口 v1

HTTP 127.0.0.1随机回环端口，Host精确匹配、Origin/redirect/cookie拒绝、固定路径POST、JSON闭合和大小/时间/并发限制。成功application/json。失败`{code:ErrorCode.wire}`保留原大写固定代码与对应status，不回异常/SQL/凭据。人Bearer与dcn1_节点Bearer不能互用。/control使用已有用户Bearer+X-DevClaw-Space；/node身份仅由节点Session解析，不允许bodyspace/node/owner、XSpace覆盖或任意URL/prompt。

请求为固定`{operation,...knownFields}`，未知字段拒绝：

### /node

- identity → `{spaceId,nodeId,ownerPrincipalId}`。
- observe，无额外字段 → `{observed:true}`；只requirements.analyze/supported=true，不body自报capability。
- poll，无额外字段 → `{runs:[Run]}`；当前Session space/node/owner的queued/waiting_node/starting/running，最多8，Group当前读取权后才返回；不返回他人节点/Group文本。
- claim `{runId}` → `{run}`，旧单attempt语义。
- start/renew `{runId,attemptId,leaseId,fence}` → 已验收`{run,input}`/`{run}`。
- settle 上述+`outcome,text` → `{result}`，A6原校验。
- inspect `{runId}` → `{run,result:null|Result}`，自身node/owner且当前Group读权。

### /control

- identity，无额外字段 → `{spaceId,principalId}`。
- authorization `{groupId}` → `{grant:null|Grant}`；当前成员与Group读取权，同事务只读；App重开/导入后先读原授权版本，不盲目假定CAS0，不新增公共API或写权。
- authorize `{groupId,nodeId,workspaceRef,expectedVersion,expiresAt}` → `{grant}`；A3原负责人owner/admin/执行与workspace ACL/CAS，不把mayConfigure当执行授权。
- revoke `{groupId,expectedVersion}` → `{grant}`。
- enqueue `{commandId,taskId,botId,expectedTaskVersion,deadline}` → `{runId,status,taskVersion,createdAt}`；A4原语义，重复deadline须保持原值。
- inspect `{runId}` → `{run,result:null|Result}`，当前用户Group读权。
- cancelPending `{runId,expectedVersion}` → `{run}`；不把已running说成已停止。
- lookupTaskNumber `{groupId,taskNumber}` → `{task}`；当前Group读权，仅TASK-正safe整数，scoped精准定位后原Task schema校验。

Run/Result JSON沿用A6小写status/毫秒ISO UTC；input有bot/botVersion/group/task/messages。授权Grant字段沿用A3（JavaInstant须显式ISO，不默认bean序列化）。无路径/token/APIkey进入响应。
