## 六个接口

| 操作 | 冻结路径 | 本轮职责 |
| --- | --- | --- |
| createBot | POST /api/bot/v1/bots | 创建伙伴及第一个不可变配置版本 |
| getBot | GET /api/bot/v1/bots/{botId} | 鉴权后读取伙伴及当前版本 |
| createBotVersion | POST /api/bot/v1/bots/{botId}/versions | CAS 追加版本，不覆盖旧版本 |
| createGroup | POST /api/bot/v1/groups | 保存独立团队、成员及固定伙伴版本组合 |
| getGroup | GET /api/bot/v1/groups/{groupId} | 当前成员读取一致的团队快照 |
| updateGroupMembers | PUT /api/bot/v1/groups/{groupId}/members | 当前管理员以 CAS 原子更新伙伴组合与成员 |

不新增列表、删除、发布、Bot maintainer 修改或超级管理员HTTP接口。Group不绑定招乎群、Thread或Runtime；Bot不启动进程、不访问知识库／仓库、不执行指令。配置中的能力和引用不授予实际执行／读取权限。
