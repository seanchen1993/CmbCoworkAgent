## 范围与模块边界

### A. dev-only 配置与工具链检查

- `deploy/dev/` 提供简洁 CLI、配置示例、README 和工具链清单。必须显式 `dev` profile，缺失/未知/prod 配置失败，不自动降级到测试身份。
- doctor 实际执行并报告 Java/Javac 8、MySQL 5.7、Node 22 和可选 Maven；不以目录存在替代可用性。路径可显式传入，不把开发者个人路径硬编码进程序。
- 已有 Maven/JDBC 缓存可由调用方显式传入；不读取用户 Maven settings、数据库默认配置或任何真实凭据，不联网下载依赖、不修改全局环境。
- 真实 S3/ES 明确 disabled，报告每项是 verified / mock / disabled / unavailable，不把 mock 冒充基础设施。

### B. 测试身份、假招乎与假模型

- Node 22 只做开发工具；提供可被后续服务消费的本地测试替身，不实现 TypeScript 生产伙伴服务。
- 替身只监听字面量 `127.0.0.1`，使用随机空闲端口。身份和请求上下文由受信任 dev 配置建立，不从请求体自报 actor/space 取得权限。
- 至少两位合成用户、两个相互隔离空间，另一个显式共享任务可模拟业务/研发合作。每次启动生成独立测试访问凭据，不在代码中放真实秘密；不开放任意主体的匿名签发接口。
- 假招乎只支持显式任务编号、合成群成员/消息、附件元信息和回执。群并发两个任务且无编号时必须提示选择，不能把“最后一个任务”作为默认写目标。未知用户、非成员和跨空间请求均拒绝。此协议是开发适配器，不宣称招乎正式协议或 Slack 回复串已经实现。
- 假模型为确定性 fixtures，返回带 mock 标记的合成分析/澄清内容，可注入超时/失败；不持有工具能力，不接收任意 URL/文件路径，不调用任何模型网关。
- 本地 HTTP 入口设请求体/条数/文本/等待上限，拒绝跨站浏览器来源及异常 Host，避免 localhost 测试能力被网页借用。不把访问凭据写入普通日志。
- 同一实例内用户/空间隔离测试要真实经过 HTTP/适配器边界；不能只证明两套不共享状态的进程彼此隔离。使用 F03 fixtures 的部分继续校验 schema；仅开发专用包络需明确与正式 API 不同。

### C. 真实 JDK 8 / MySQL 5.7 兼容探针

- 使用真实 JDK 8 编译并运行小型 JDBC 探针，class major 52。探针与测试 SQL 放在开发/测试目录，不创建生产 Bot CRUD，也不引入未确认 Spring Boot BOM。
- 从已有 MySQL 5.7 二进制启动独占临时实例：新建私有临时目录、`--no-defaults`、独立 socket/pid/log/data、仅 loopback、禁止复用已有数据库。不得连接默认 3306 或自动采用用户现有数据库。
- 初始化阶段禁用网络，仅在设置专用随机测试凭据后允许 loopback JDBC；凭据不在命令行/普通日志暴露，不需要用户 root 密码。客户端也必须忽略默认配置和登录路径，不读取已有凭据。
- 使用有限权限的测试账号/测试 schema；SQL 仅作用于本次新建实例。验证版本为 5.7、UTC、utf8mb4（含中文/emoji）、DATETIME(3)、READ_COMMITTED、commit/rollback、唯一键和 expectedVersion 条件更新。
- 进程启动/关闭、探针/故障路径有超时和 finally 收尾；只停止本次实际持有的子进程，不按模糊进程名或未经核对的 PID kill。保留可诊断但脱敏的报告；不做宽范围 rm/reset。
- JDBC 8.0.33 已有本地缓存可显式传入，Java/SQL 探针无需框架。缺失工具时退出非 0 并明确不可用；不能悄悄 skip 后总结果显示通过。

### D. 验证入口与交付

- 一个离线检查入口运行 dev 配置/替身/负向安全测试；一个明确的真实基础设施检查入口启动隔离 MySQL 并运行 Java 探针。必要时由统一入口串联，但输出严格分开 mock 和 real。
- 空临时环境启动 → 两用户允许共享与禁止跨空间 → 故障注入 → 正常退出 → 重新从空环境再运行。验证端口、进程与临时目录归属，不遗留运行服务。
- CLI 不自动使用 Docker、下载镜像、联网安装、访问真实平台或启动现有 App；依赖不足须准确报告。
- 文档列出实测命令、版本、约束、后续 Spring Boot/S3/ES 接入点；不得声称已实现生产认证、完整 Bot API、持久任务/Outbox、Runtime、S3 或 ES。

## 验收门槛

1. 独立新环境可重复启动/停止，无遗留服务；缺工具/错误版本是失败不是跳过。
2. dev-only、回环限制、凭据/身份防伪、同实例两用户/空间隔离、群多任务路由和 mock 错误行为均有执行型测试。
3. 主代理真实 JDK 8 + MySQL 5.7 独立复验上述 JDBC/SQL 行为；不能以日志片段或字符串测试代替。
4. F03 契约入口、node/web 类型检查通过；原代码/契约无变更。若 package 脚本受影响复核原脚本完全保留。
5. 审阅实际 diff，记录候选 code commit 与报告-only commit，所有命令退出码和仍运行句柄。子代理自测只能交回 review_pending。
