# F03 · 核心接口契约

任务单版本：1 · 2026-10-01（2026-10-02 补充幂等语义澄清）· 状态：implementing，F02 已验收，当前由 F03-A01 唯一实施写者接续。主代理负责设计判断与边界，子代理负责批准契约的文件化、类型/fixture 与验证代码。

## 目标

在不绑定服务端实现语言的前提下，冻结 Bot、Group、Task、Artifact、Approval 与 Runtime 的第一版契约，为后续并行实施提供统一依据。

## 输入

完整阅读 [主代理冻结的 v1 设计决定](F03-contract-decisions.md)，以及 `../../devclaw-bot-implementation-plan.md` 第三至六节。前者是本轮实施边界；后者更大范围的路线不是额外实施授权。已有 IM V1 Schema/fixtures 保持兼容，不静默增加群语义。

## 已冻结的设计

- 一份 JSON Schema 2020-12 定义所有 DTO；OpenAPI 3.1 引用，TypeScript 确定性生成，不手写平行类型。
- Bot/Group、模式/成果交接、Runtime 三个核心对象独立，具体字段/端点/状态/消息见设计决定。
- 服务端认证与授权真相不接受请求自报；写操作命令幂等与 CAS；成果/批准绑定准确版本；Run/Attempt/Delivery 状态分离。
- 契约级正负向验证及可执行参考模型，不实现生产 HTTP/WSS 服务、数据库或真正的授权引擎。
- 若发现设计内部矛盾，带具体场景交主代理解决，不自行更改对象定义或用宽松 any/metadata 绕过。

## 文件范围

- `contracts/bot/v1/`：schemas.json、openapi.json、runtime.schema.json、state-transitions.json、fixtures/ 与 README.md。
- `scripts/generate-bot-contract-types.mjs`：纯离线生成器，支持 `--check`，确定性输出；不拉取远程 schema。
- `src/shared/bot/contracts.generated.ts`：生成产物；不改变原有 shared 类型。
- `tests/bot/`：契约 fixture runner、参考状态模型与场景测试，测试只使用合成数据。可用 mjs＋node:test 或 tsx，主入口必须可一次运行并失败返回非零。
- `package.json`：仅新增本契约的 check/generate 脚本及固定已有版本的 ajv/ajv-formats devDependencies；`package-lock.json` 仅对应依赖元数据，不升级其他依赖、不联网安装。
- 本人的 `docs/devclaw-bot-delivery/attempts/F03-A01.md`。

不修改主代理任务单、state/HANDOFF、F02 代码、原有 IM 契约、服务端/部署目录。主代理验证是否可使用上一任务依赖树；不要共享可写 node_modules cache 到正在测试的另一个工作树。

## 验收

- 同一份契约定义供各端使用，不产生互相矛盾的手写 DTO。
- 正常输入、重复命令、同 ID 不同载荷、版本冲突、身份伪造、凭据误传均有 fixture/验证。
- 任务、执行和消息交付的完成条件分开；结果未知不自动重放。
- 不能把 Group 等同招乎群、把 Bot 等同 Runtime 或把一个 Group 永久绑定一条 Thread。
- 原有 IM V1 契约测试继续通过；主代理检查与产品计划的一致性。
- 设计决定中每条 endpoint 的请求/响应、每个 Runtime 变体有正向 fixture，关键约束有真实负向验证；状态样例必须实际执行参考模型而非字符串匹配。
- `--check` 检测生成产物漂移，未知 schema 关键字不悄悄退化成 any；schema 枚举、状态表、生成类型一致。
- 新增契约入口全部通过，node/web 类型检查通过；原 `test:im-v1` 19 个脚本通过（Node 22）。主代理独立复跑。

## 非目标

不实现整个 Java/TypeScript 服务端、不创建真实数据库或对象存储资源、不进入云 Runtime 开发。服务端技术栈和内网资源版本未定，不妨碍语言无关契约设计，但不得擅自锁定生产依赖。

生成 TypeScript 的校验通过不等于已经生成/编译 Java DTO，README 应写清后续 Java 消费方式与待验证项。不宣称参考模型测试提供生产 exactly-once、权限隔离、S3 不可变或跨重启恢复保证。

## 恢复

每次提交记录契约版本与测试快照。额度中断后从已生成的文件和 fixtures 继续，不重新另起一套不兼容接口。
