## Java / SQL 兼容边界

- 真实 JDK 8 编译并运行，class major 52。禁用 record、var、List.of、Java 11 HTTP Client 等后续 API。
- MySQL 5.7 不使用 CTE、窗口函数、SKIP LOCKED、CHECK 约束作为安全保证。以应用校验、唯一索引、事务/CAS 为后续设计基础。
- JDBC 探针验证 UTC、DATETIME(3)、utf8mb4、READ_COMMITTED、事务回滚、唯一约束与版本条件更新；仅测试表，不提前设计 dc_bot_* 生产表。
- 不使用真实企业登录、模型、发布、IM、S3 或 ES；不开放公网端口，不安装系统服务，不修改全局数据库配置。
