# M05-06 任务关联本机对话

2026-10-20 用户批准：任务可以由本机对话、项目会话或未来云端会话承载；本轮先关联本机「对话模式」。root 设计与验收，原 6.1-sol/xhigh 唯一实施。此片不恢复 M05-04/05 的完整功能验收。

## 产品关系

任务保存工作目标、所属 Bot、业务状态和承载会话的引用。会话保存消息、执行设置和工作目录。一次执行只是会话的一轮处理；回复成功不自动确认业务任务完成。任务与其承载会话使用同一 Thread ID、同一消息记录和执行队列，两个入口不复制历史，也不各自启动 Agent。

Bot 左侧仍只显示 Bot/群。独立任务仍在 Bot 右侧；选中任务后增加「在对话模式打开」和实际工作目录。对话模式可以发现这些本机任务会话，并显示所属 Bot、任务状态、返回 Bot 任务的入口。任务与 Bot 主对话仍有返回关系，主对话不因本片变成独立任务。

允许用户显式把已有普通本机对话关联为某个 Bot 的任务，不自动执行一轮，不复制历史，不改变原工作目录、模型及执行设置。一个本机会话同一时刻只属于一个任务；重复操作返回同一关联。关联前确认会话和真实后台执行均空闲。正在执行、已绑定、项目模式、远程/历史收件箱、群会话或模拟渠道均不能被误接纳。

## 扩展与本机权威

承载引用使用可区分的类型：本机普通对话、项目会话、云端会话；标识由主进程/所属 Host 核验。当前仅实现本机普通对话适配，其余返回明确不支持，不回退到本机、不显示可用的空入口。不为未来实现建立空表或另一套会话数据库。

已有本机独立任务按原固定 Thread 关联；外部模拟渠道保持原来源/受众边界，不进入普通私有对话列表。新建任务可沿用现有 Bot 工作目录，界面应说明共享目录；接纳的既有会话保留它自己的目录。目录读取和打开由主进程解析真实会话，renderer 不传任意路径替换权威。

## 单一执行与数据保护

两个入口复用同一受管会话实现，发送、停止、排队、审批、完成/继续、草稿、附件及模型配置按同一目标处理。普通入口不能因 Bot 空闲而绕过 Host 直接运行；IPC 同样阻止此旁路。不得用普通 ChatContainer 的裸发送或文件视觉编辑提交绕过任务来源和完成状态。

既有普通对话关联保留工作目录、模型、执行模式及其他原设置；只新增必要的任务身份。Bot Runtime 不再无条件覆盖这些已关联会话设置。检查原 beta 的文件页签、预览、目录/模型设置、归档、删除、导出、fork 等入口，保持未关联会话原行为；关联会话冲突操作应走一致的主进程规则和清楚的 UI。

跨 control.sqlite 与会话存储的绑定采用可恢复的持久准备与身份核验；失败或崩溃不能产生可发送的半关联，恢复只完成绑定，不自动运行。删除重建同名 Thread 不得被当作原会话接续。保留关联来源和拥有权，删除 Bot 不得删除用户先前的普通会话；解除绑定恢复其普通身份。删除/归档入口不能留下任务指向已丢失会话而继续执行。

## 验收范围

1. 既有任务在两个入口看到相同消息、状态、工作目录；往返保持草稿和发送目标，普通 Bot 主对话及群/渠道边界不变。
2. 既有普通对话显式关联后 ID、消息、目录和原设置不变，无新执行；重复、冲突、忙碌、崩溃恢复和身份变化有针对性验证。
3. 两入口发送/停止/完成/继续走同一 Host；完成状态不能被裸 IPC、快捷操作或文件编辑旁路。原 beta 未关联会话行为不变。
4. 针对所改路径运行必要单元/集成测试与 Node/Web 编译。使用自有临时 profile 和 fake 模型；root 审查后升级当前 UI 预览并检查导航与目录展示。不要将本片检查宣称完整 MVP、M05-04/05 或真实 IM 验收。
5. 现有用户预览、模型配置、消息和文件完整保留。实施者不改用户 profile、不调用真实模型、不在预览运行时覆盖 out；构建与升级由 root 协调。

不触及 Java/IM 仓库、ES、真实后端或定时任务，不 push/deploy。
