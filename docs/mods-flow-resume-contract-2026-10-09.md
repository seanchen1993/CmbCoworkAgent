# Flow 安全续跑实施契约

这是最终方案 B3 的实现细化。B2 已提供只读诊断，旧记录没有可复验绑定，不能迁移成可续跑记录。诊断结果不是执行授权；恢复命令必须由用户点击并重新验证。

## 首个开放范围

先开放新建的普通本地宿主 Flow：直线 Agent 步骤、已结算原生检查、人工确认；没有条件／跳转／修复回路。只复用连续且可重新证明的已结算 Agent 前缀。检查和确认重做；任何可能产生效果的未结算操作，包括项目测试脚本，均阻断恢复。

首轮不开放带 Function Mod、Skill、MCP、Harness 业务绑定或 Worktree 子任务的结果复用。来源配置必须有可复验完整快照才逐步开放，不能因为当前模型／插件可用而推定与旧运行相同。旧运行、取消任务、已进入最终提交、来源不明、产物改变、预算用完均给出明确原因。

这里的范围检查必须覆盖 Agent 实际运行器和调用依赖，不能只检查 Flow 的 step.kind。普通 Agent 的工具目录、Skill 注入、MCP、子任务、动态工具和 Hook 都可能引入额外依赖；首版只有宿主能证明这些路径未开放／未使用且调用记录完整时才生成恢复资格。出现隐式调用、动态能力或缺少可证明记录时，该运行保持不可恢复。不能为了开放恢复而悄然改变已有普通聊天或普通 Flow 的工具策略；需要受限执行模式时，作为显式配置保存并展示。

该范围是首个真实续跑路径的安全门槛，不代表最终方案的其他集成已完成。

## 新证据

新运行记录增加版本化恢复证据，与既有完成检查回执分开：

- 会话实例 token 与创建时间、项目规范路径、原始流程来源和快照。
- 当前模型引用及配置摘要、实际 Agent profile 摘要、适用 Hook／Claw 选择／执行配置摘要。原始凭据不落盘。
- 产物绑定沿用真实有界文件／Git 采集，保留配置、项目检查配置、文件、状态和需求摘要。只有运行 id、turn id、runtime generation 这三个执行实例字段不参与跨运行产物身份；权限永不由该摘要授予。
- 默认 Git diff 采集不是完整恢复证明。恢复绑定必须覆盖声明和实际读取／产出的依赖，包括 Git ignored 的构建产物；记录覆盖范围并在重新采集时核对新增、修改、删除及符号链接。无法界定依赖、未纳入采集、超过文件／字节上限或无法稳定读取时返回未验证。不能用忽略 node_modules／dist 等目录的默认完成检查指纹宣称全部产物未变。
- 每次执行前落盘 executionId，结算后落盘输入／输出恢复证据。宿主读取事实产生证据，模型文字不能填入。
- 缺失或不支持的证据只影响恢复资格，不能让原有正常执行误报失败；但准备恢复后无法验证时必须停止，不能退化为从头执行。

纯读取观察不能调用 session／prepare、创建运行器、清理目录、连接 MCP 或申请授权。恢复启动可以正常 prepare，但准备后、首次操作前必须再次核对全部绑定。任何模型／配置／授权／产物漂移均停止。

## 原子预占与历史保留

在同一线程的持久历史键内一次原子写入来源 consumedBy、新运行、父运行关联、恢复次数和共享预算。执行前必须先完成持久化。同期双击或多个异步观察完成后，仅第一个 sourceDigest CAS 能成功；另一个返回既有恢复结果或明确已消费，不再启动业务。

新运行的可复用前缀保留 `reusedFrom` 来源执行标识，UI 明示复用，没有发生的新调用不能计作真实调用。复制的结果不再消耗一次执行预算；原运行真正执行过的次数仍计入祖先预算。

保留活动运行及其父链。历史裁剪按完整的已结束恢复链进行，不能删掉仍被保留子运行依赖的来源；容量不足时拒绝新运行，不能破坏活动记录。损坏／缺失父链不能获得新预算。

时间上限沿用根运行 deadline，包含等待审批及停机时间，恢复不重置时间；恢复链次数有单独上限。既有 maxExecutions 统计整个父链真实执行次数，结果不明也计入。新执行前再次核对剩余预算。

## 验收

使用独立临时数据库与受控宿主验证：成功复用前缀；旧记录阻断；未知工具或检查不重放；审批 nonce 不复用；修改产物／模型／配置／会话实例阻断；重复点击只创建一次；持久写失败不执行；预占后崩溃可识别新运行且不再次消费旧来源；子运行继续保留祖先预算；历史容量不会裁剪活动父链。

额外验证 Agent 隐式调用 MCP／Skill／子任务时不能取得首版恢复资格；ignored 文件的修改、删除、新增，以及未纳入绑定的依赖均阻断复用。恢复资格要由宿主依赖覆盖证明产生，模型自述“未使用”无效。

增加真实进程重启的验收，不以重新构造内存对象替代重启测试。主进程、preload、UI 走真实进程链路，浏览器回归验证按钮只在可恢复且范围一致时显示、过期观察不触发恢复、复用记录明确可追溯。
