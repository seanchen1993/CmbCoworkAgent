# 模组长提示与日志兼容

Claude Code 2.1.290 包内声明明确：日志、临时提示和固定状态接受长文本，显示时取
前段。当前工程超过 10,000 字符就拒绝整个调用，插件可能因此没有状态提示。

本次沿用原方法、权限和界面位置。完整输入先经过原模组处理及内容保护，只有保护
完成、授权仍有效之后，才生成供显示的文本。主进程日志及对外展示数据保留前
10,000 个 UTF-16 单元；桌面显示前 2,000 个。截断后不成对的代理字符显示为替换
字符，完整表情保留。模型输入、正式对话记录和工具执行不受这些显示文本影响。

去掉三个方法自身的 10,000 字符拒绝；原 1 MiB JSON 传输预算、对象字段检查、
撤权、取消、调用归属、日志顺序、最后一次状态更新、提示停留计时与展示票据保留。
传输预算仍是工程边界，不声称接受无限大的单次跨进程请求。

预计修改共享日志和状态的输入验证、一个纯文本显示函数、主进程日志及状态保存、
桌面两个显示组件。既有快照检查继续限制对外展示大小和原归属，不允许插件增加
别人的日志、状态或提示。无需新增权限、运行入口或对话写入方法。

验证包括真实插件传入 30,000 字符、上层处理器收到完整输入、内容保护收到完整
改写后输入、受保护内容才截断、调试日志和展示长度、显示边界表情、不成对字符、
拒绝/撤权/取消零晚写。原时序、队列容量、提示计时和多插件归属测试全部保留。
两个独立方案评审通过后实施；源码检视、真实插件回归和桌面验证另行记录。
