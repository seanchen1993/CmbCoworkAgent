## 回归与过程记录

最终构建、渲染器 TypeScript 检查、12 个单测文件共 180 项以及 9 组桌面和浏览器用例均退出 0。界面用例包括详情卡片、招乎会话、群文件历史、记忆配置、成员和消息操作、Feature 面板、浏览器控制、新会话草稿、任务目录。任务目录用 45 条工作记录验证分页与展开。浏览器预览回归核对仅订阅当前来源，移交与归还使用原任务归属。

- 初次桌面编辑回读用了严格的标签文本匹配。已有正文会进入 textarea 的 DOM 文本，随后还观察到本地 Markdown 存储的首尾换行。改用输入框的无障碍名称，比较去掉首尾空白的正文，保留真实保存与回读。
- 扩大回归时，群资料预览导出的旧断言只检查群和路径。核对既有接口后补上建议文件名，继续分别验证预览导出和列表导出。
- 例行编辑器的 Node 测试直接调用组件，自定义 Hook 替身缺少 useId，且只遍历 children。补上标识和卡片标题栏操作后，该套件 14 项通过。
- 增加对比度验收后，首轮页面求值因转译辅助函数作用域失败。改为在页面采集像素，在测试进程计算比值，再跑完整桌面路径，通过。

- 首次新增例行编辑返回检查，在弹窗刚点击关闭时就断言焦点，得到 false。改为等待实际焦点恢复。在另一工作区尝试复用构建时，测试入口的来源校验先退出。最终在构建所属工作区重跑，编辑取消、焦点恢复、滚到底部再切 Bot 均通过，五张截图与前一轮一致。
