# 主 Bot 对话中独立任务中断提示的布局

2026-11-18 17:38–17:41（北京时间），在 macOS 15.4 arm64、Electron 39.8.10 和 Node.js 22.23.5 上复测。使用隔离的本地配置、实际桌面应用和 SQLite，将示例独立任务“查看今日报表”置于中断状态。本轮只验证界面，没有调用模型或连接招乎。

## 复现与结果

从侧栏打开“报表助手”主对话。测量任务提示卡顶部到标题栏底部的垂直距离，并验证顶部按钮能被点击、点击状态能进入原任务。负值表示两者的布局区域相交。两版使用同样的任务数据和判定条件。

| 窗口宽度 | 修复前 | 修复后 |
| --- | --- | --- |
| 1280 px | −62 px，状态文字被标题栏右侧按钮遮挡 | 6 px，标题、状态和按钮均可见 |
| 1000 px | 首个断言失败后停止，未测量 | 6 px，点击“执行已中断”打开对应独立任务 |

修复前，68 px 高的标题栏始终以负边距覆盖下一行，任务卡片从第 6 px 开始。修复后，仅在标题栏紧邻聊天记录时启用悬浮布局。返回主对话后，将示例任务标记为完成，卡片随即消失，聊天记录恢复到悬浮标题栏下方，顶部无额外留白。

- 使用 `codex/merge-uat-into-bot-beta`。对照构建包含 `fd5176760` 提交的例行任务改动，入口 CSS 的 SHA-256 前缀为 `fd827199cc8e67`。修复构建基于该提交加布局改动，CSS 指纹为 `4dbbaccd88c3d3`。
- 首轮对照在重叠断言处失败，退出码为 1。修复后两个尺寸和往返导航均通过，退出码为 0。第二轮增加截图和状态文字点击检查，复现同一组数值和退出码。相关任务状态及待处理事项单元回归共 105 项，通过 105 项。
- 运行 `node scripts/run-bot-integration-e2e.mjs --build-only`，再将输出目录设为 `BOT_TEST_APP_OUT`，执行 `node --import tsx tests/bots-work-attention-layout-app.spec.ts`。该用例也已加入默认的 Bot 集成测试。
