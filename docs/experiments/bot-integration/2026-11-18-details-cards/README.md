# Bot 详情侧栏的卡片和群聊切换

2026-11-18，北京时间 18:21–18:47。本轮以用户截图下半部分的“例行”和设置卡为参照，检查个人 Bot、App 群和招乎群的详情入口，并验证从一个会话进入另一个会话后的任务归属。

## 条件

使用 macOS 15.4 arm64、Electron 39.8.10、Node.js 22.23.5。桌面用例加载生产构建、独立的临时配置及 SQLite，导入两位示例 Bot、一个 App 群和一个招乎群绑定。私聊中有两个开放任务、一个已完成任务和一项已暂停的周五例行，招乎群中有一项群内任务。所有名称和任务均为合成数据。测试进程阻断外部 HTTP 请求，未调用模型或连接内网招乎。

集成分支基线为 `fd5176760`，叠加当前工作区的界面改动。隔离验证构建的入口 CSS 和 JS 的 SHA-256 前缀分别为 `70341d81aa42fe` 和 `a1112564132b66`。同步到 `codex/merge-uat-into-bot-beta` 的实际工作区后，重新构建（CSS `4c8357b7e975f6`、JS `8c5512f8d9807a`）并重跑桌面回归，三张截图与隔离验证结果逐字节相同。

## 运行记录

- 首轮桌面断言用同一个标题查找了任务和例行，随后一次用同名“返回主对话”命中了两个位置。两次均退出 1。调整为查找相应区域的控件。另一次尝试在窄屏拖动分隔线，原布局在这一宽度自动收窄并隐藏分隔线，改为测量实际宽度。
- 打包版从 App 群切到招乎群时出现“界面渲染失败”。定位轮记录到 `client.subscribe is not a function`。模拟客户端的订阅方法可以被对象展开复制，实际注册的客户端通过代理提供方法，展开时丢失订阅。保留原客户端，在目录内选择当前群的分页接口后，同一路径通过。缺少群目录接口时有独立用例验证私聊列表不会被读取。
- 独立的目录回归起初仍查找旧的“新建独立任务”按钮。与实际“添加任务”入口对齐，并补齐取消后的焦点恢复。草稿回归最初缺少预览导出，更新后又缺少上下文默认的工作区文件列表，分别导致打包错误和队列断言超时。补齐测试环境后两组均通过。
- 最终桌面卡片回归退出 0。浏览器回归通过了招乎群离线和解绑、群内任务、Feature、草稿切换及 45 条任务的加载与搜索。7 个定向单测文件共 150 项全部通过，渲染器类型检查通过。本轮未测量业务处理耗时。

## 复现

先用 Node.js 22 执行 `node scripts/run-bot-integration-e2e.mjs --build-only`，将输出的隔离构建目录设为 `BOT_TEST_APP_OUT`，再执行 `node --import tsx tests/bots-details-cards-app.spec.ts`。截图写入该构建目录的 `artifacts`。该桌面回归也在默认的 Bot 集成测试中运行。
