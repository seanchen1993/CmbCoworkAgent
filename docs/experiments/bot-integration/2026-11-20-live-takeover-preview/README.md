[上一轮输入控制](../2026-11-20-work-input-control/README.md)将接管期间的输入和原运行收尾放在同一条件下。[上一轮侧栏已读](../2026-11-20-bot-sidebar-unread.md)只确认 Bot 任务概览。此次更改了两个验收条件：取得控制权后立刻可以输入；看到任务预览后确认这条任务已展示的活动版本。

| 操作 | 实际结果 |
