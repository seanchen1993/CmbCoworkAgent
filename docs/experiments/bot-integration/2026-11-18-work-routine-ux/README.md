# 独立任务与例行任务的界面走查

2026-11-18，Asia/Shanghai。上一轮检查了详情栏的卡片和导航。这次沿用户的实际路径，从聊天回执、侧栏创建入口走到任务会话或例行编辑器，再返回原处，检查目标定位、状态操作和键盘交互。[上一轮记录](../2026-11-18-details-navigation/README.md)

## 环境和验收

集成分支 `codex/merge-uat-into-bot-beta`，基础提交 `fd5176760`，包含本地待提交的详情栏改动。macOS 15.4 arm64、Node.js 22.23.5、Electron 39.8.10。生产构建的渲染器入口 SHA-256 前缀为 JS `27debd02ad93528e`、CSS `f137eb1d494e4e48`。本轮增加观察脚本和记录。

用临时 SQLite 准备一个私人 Bot、一项已回复的独立任务和五项已暂停的周例行。主会话内放入指向第五项的合成日程回执，随后在真实桌面应用中操作。验收条件是点击对象能到达该对象、返回入口指明去向、同类表单支持一致的键盘操作、保存后能读到正确数据。群聊使用本地模拟绑定，调度用例使用本地模拟模型，未连接内网招乎。

## 测试中断与边界

- 旧的 `tests/bots-conversation-link-app.spec.ts` 直接在常驻页头查找工作目录，超时并以 1 退出。按当前“更多任务操作 → 工作目录”的路径定向重跑到关联和复制成功，退出码 0。原脚本之后的场景未由此次定向重跑覆盖，完整套件仍待更新。
- 首轮观察用同一个无障碍名称选择返回按钮，匹配了两个元素。将点击范围缩至页头，并保留对整页可见返回按钮的独立计数。第二轮记录到三处入口，其中两处位于相邻的页头行。随后又加入真实创建、保存与完成动作。对群界面的首次运行漏传构建目录，以 1 退出，补入本次构建后通过。
- 日程删除验证到取消。群内真实消息送达和真实模型输出质量不在这次界面走查范围内。

## 复现

使用 Node.js 22 在目标工作区构建隔离应用，将脚本打印的构建目录设为 `BOT_TEST_APP_OUT`，再在同一工作区执行观察脚本。每次生成独立输出目录，使用临时配置和合成数据。

```sh
node scripts/run-bot-integration-e2e.mjs --build-only
node --import tsx docs/experiments/bot-integration/2026-11-18-work-routine-ux/inspect.mjs
```
