# Bot 在私聊中删除任务和处理关联会话

2026-11-18（北京时间），在 macOS 15.4 arm64、Electron 39.8.10、Node.js 22.23.5 上验证。集成分支基线为 `fd5176760`。测试使用临时配置、真实桌面渲染器和 SQLite，由回环地址上的脚本模型发起工具调用。所有名称和历史均为合成数据。

## 验收

用户明确点名唯一的本地独立任务时，只需提出一次删除要求。若操作涉及原普通会话的历史，用户应能在发起操作的私聊中选择处理范围。切换到其他 Bot 时，选择应留在原处。

| 在 App 中的操作 | 观察到的结果 |
| --- | --- |
| 输入“删除「临时周报」” | 回执为 `deleted`，已初始化的任务会话从数据库消失。 |
| 输入“删掉「已关联工作」这个任务”，切换到另一位助手，再回来 | 卡片只在原助手私聊可见，仍可选择“仅解除关联”。 |
| 选择“仅解除关联” | 回执为 `detached`，原普通会话及关联前写入的消息均保留。 |
| 要求删除普通会话，先选择“保留会话”，再重新发起并选择“删除会话” | 先收到 `cancelled` 并读回原消息，随后收到 `deleted`，原会话被清除。 |

在上述整段交互中监听网页原生对话框及带有 dialog 或 alertdialog 角色的界面元素，共观察到 0 个全局弹窗。[查看私聊卡片截图](chat-choice.png)

## 回归与边界

- 17 个定向测试文件共 344 项通过。覆盖同名任务、含糊或经输入钩子改写的指令、打开网页时解除关联、取消、重复调用、会话身份与版本核对、草稿和远程作答隔离。主进程与渲染器的 TypeScript 检查通过。
- 首两次桌面用例在等待首条删除回执时超时。第二次的请求记录只包含新 Bot 的欢迎流程。随后预置已经完成欢迎的 Bot，通过聊天框的发送按钮发送指令，三种操作通过。最终复测还检查了普通会话删除、关联前的消息内容和原生对话框计数，退出码为 0。
- 额外运行旧的手动关联桌面用例 `bots-conversation-link-app.spec.ts`。在改动前的集成构建和最终构建中，均已完成手动关联，随后在第 445 行查找标题栏的“工作目录”按钮时超时，退出码均为 1。这个入口已在“更多任务操作”菜单中，旧用例余下步骤未执行。
- 本轮测量交互和数据结果。脚本模型固定调用指定工具，真实模型对不同自然语言的理解、内网招乎链路与生产耗时均未测量。

复现时先运行 `node scripts/run-bot-integration-e2e.mjs --build-only`，将输出目录设为 `BOT_TEST_APP_OUT`，再运行 `node --import tsx tests/bots-conversation-actions-app.spec.ts`。
