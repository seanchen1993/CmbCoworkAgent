# 实验记录模板

每轮实验使用独立记录，失败、停止和无改善的轮次也保留。正文时间用 Asia/Shanghai，机器数据保存明确时区或 UTC。

## 实验目的

- 用户问题与可验证假设：
- 本轮相对上一轮的改变：
- 对照组或基线记录链接：

## 条件与复现

- 时间、环境、真实或模拟模型、模型版本及已知参数：
- 代码分支、提交号、未提交差异、构建指纹、提示词/工具/脚本版本：
- 用例输入与材料（脱敏后），初始会话/记忆状态：
- 运行命令、用例选择、并发数、审批设置：
- 验收标准；相对上一轮是否修改标准或输入：

分别记录路由偏好、实际产物正确性、界面、套件结果。保留 stderr/错误与退出状态；未知字段留空，不从后来的运行回填。缺测不计通过，模拟结果不计真实模型效果，后续轮次不重复计为独立样本。

## 结论与后续

- 哪些证据支持或反驳了假设：
- 已证实的问题与仍待确认的解释：
- 未覆盖场景和结论适用范围：
- 下一轮要改变或验证什么：

原始记录不得写入 API Key、登录凭据、内部接口地址、个人路径或真实业务文档。必要时保存脱敏副本并标明变换，敏感原件不提交 Git。原始数值不因复测通过而覆盖；修正记录写明原因并链接原条目。
