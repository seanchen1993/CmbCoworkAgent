# Bot 例行任务在后台执行

2026-11-18，在 macOS 15.4 arm64、Node.js 22.23.5 上验证。最终集成分支为 `codex/merge-uat-into-bot-beta`，基线为 `4a266fa08605`，测试构建包含本次工作区改动。

## 要验证的行为

用户只需说明什么时候做什么。创建日程时，Bot 区分发送原文提醒、查看已有进展和实际执行工作。执行型日程在保存时绑定原任务或分配一个专属任务。后续触发沿用这条任务会话及其工作目录。通过斜杠选中的技能随日程保存，执行时按 Bot 当时获准使用的技能目录核对并激活。

## 本地案例

| 场景 | 操作 | 观察结果 |
| --- | --- | --- |
| 定时技能 | 在桌面主对话选中 `/slash-prd-fixture`，要求“五秒后按所选技能在指定项目写 prd.md” | 主 Bot 用一次路由调用保存日程，回执给出下次执行时间。保存时没有启动执行轮。到点后独立任务读取已安装的 `SKILL.md`，写出含 `SKILL_PRD_OK` 的 `prd.md`。执行前后两个技能钩子的会话 ID 都指向该独立任务。原主对话收到完成回复。 |
| 主对话与固定提醒 | 让技能任务停在尚未返回的工具决策处，回到主对话发“主对话还在吗”，然后安排“三秒后提醒我到点检查工时” | 主 Bot 回复“在，后台检查还在进行。”固定提醒按原文出现在主对话。两条消息到达时工作线程仍在运行。提醒没有分配独立任务。 |
| 原任务续办 | 第一次执行完成后，再安排“三秒后复查刚才那份报告” | 第二次执行读到了第一次的助手回复，又从原目录读出上次生成的标记。两次执行各有触发记录，共用同一组 `workId` 和 `threadId`。续办结果回到了原主对话。 |
| 招乎群回传 | 给同一 Bot 绑定两个模拟招乎群，在第一群安排周期检查；在后台运行期间发“你好”，并推进到下一次触发 | 第一群先收到“群主对话在线”，随后收到一次“检查完成：7 条”。所有网关回执都指向第一群。执行期间第二次到点没有重复启动。解除该群绑定后日程自动暂停。 |
| 群内固定提醒 | 在群里安排“每天九点提醒我打卡”，推进两个触发时间 | 模拟网关在两个时间点各接收到一条“记得打卡”，两次发布均落入原群。到点投递占用的模型执行次数为零。 |

桌面样本通过 Playwright 调用真实 Electron 预加载接口，使用隔离的应用配置、SQLite、文件系统和技能钩子。本机模型替身根据收到的消息与工具回执提供确定性响应，以便在指定位置保持后台运行。群聊用例通过 App 侧 IM 接入服务和模拟网关，验证会话归属与发送回执。此实验未连接内网招乎或在线模型，耗时只反映本机这条链路。

## 失败与复测

| 阶段 | 结果 | 处理 |
| --- | --- | --- |
| 第一轮定向回归 | 578/587 | 修正宿主发布调用，更新工具入参断言。将“在主线程执行”的旧断言改为检查后台运行、并行交谈和原群回传。 |
| 固定提醒回归 | 374/376 | 对齐固定提醒的工具说明与周期能力。随后 208/208 项定向检查通过，另行筛选的两项群聊用例通过。 |
| 集成构建与类型检查 | 首次构建成功，Web 类型检查失败 | 收窄技能日程回执的结构并验证执行目标。最终 Node 和 Web 类型检查均通过。 |
| 第一次扩大回归 | 3,094/3,102 | 六项需要本机回环网络。另两项暴露旧日程待执行命令可能重复触发，以及执行提示缺少既有要求。调度器现在等待旧主线程上已接受的执行结算，再启用后台去向；保留了要求日程指令独立、完整的提示。 |
| 最终集成回归 | **99 个文件，3,102/3,102 通过** | 使用本机 HTTP 和 WebSocket 重跑同一范围，耗时 177.96 秒。覆盖旧日程迁移、重复触发、重启后的技能身份、任务归属、解绑、静默结算和回执。最终 Electron 场景另行通过。 |

## 复现

仓库安装依赖后，在 Node.js 22 环境中运行。第一条命令输出隔离构建目录，将其填入第二条命令。桌面实验使用临时配置并安装测试技能。

```sh
node --import tsx scripts/run-bot-integration-e2e.mjs --build-only
BOT_TEST_APP_OUT="<隔离构建目录>" node --import tsx tests/bots-scheduled-skill-app.spec.ts

npm run typecheck
node node_modules/vitest/vitest.mjs run src/main/bots src/shared/bots src/main/ipc/bots.test.ts \
  src/main/agent/bot-skill-dispatch.test.ts src/main/agent/bot-skill-dispatch-model.test.ts \
  src/main/agent/bot-dispatch-feedback.test.ts src/main/agent/standard-thread-turn.test.ts \
  src/renderer/src/lib/bot-schedule-view.test.ts src/renderer/src/lib/bot-execution-visibility.test.ts --maxWorkers=2
```

测试入口见[桌面技能与并行交谈](../../../tests/bots-scheduled-skill-app.spec.ts)、[日程与原任务续办](../../../src/main/bots/work-schedules.test.ts)及[招乎群内回传](../../../src/main/bots/im-channel.test.ts)。
