# 我的 Claw 与显式流程迭代

目标：普通聊天由原 Agent 执行，选择的 Function Mods 参与其事件链；固定流程由用户明确启动。

两位独立 agent 已评审方向，实施约束如下：

- 项目级命名能力组合，只作用于本地普通聊天；Harness、远程、后台会话保持原配置。内部流程子任务继承父普通会话选择。
- 未配置沿用原行为；空组合不加载 Function Mods。保存插件 ID、名称、代码摘要，使用时与当前授权核验；不自动授权。
- 统一运行入口过滤，包含图就绪、命令、工具、UI 和冷启动。运行中不允许应用配置，避免打断其他会话；切换后失效旧授权上下文。
- 完成规则仍为项目共享的应用配置，不伪装为组合快照。有阻止完成/自动修复规则的插件不得被组合排除。
- 普通发送不启动工作流；独立任务输入和启动按钮，沿用原审批、取消和版本校验。本次目标不改模板。
- 结果通过“带运行摘要追问”明确放入可编辑聊天草稿；不会自动发送或假定模型看得见界面卡片。
- 组合页说明具体范围、触发方式和共享规则；保留上传与授权页，提供直达入口。

验证：配置持久化/版本冲突/损坏/撤权/项目隔离；运行入口交集和空组合；聊天 A→B→A 及并发；真实 Electron 受控模型验证聊天路由、流程和插件行为；回归旧 Plugin/Harness、构建、类型检查与相关测试。已知全量基线失败单独记录，不冒充本轮全通过。
