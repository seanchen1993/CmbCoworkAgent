# 插件组件选择：本轮实施契约

开发目录为 `C:\ai\CmbCoworkAgent-mods-v2`，分支 `codex/mods-v2`。本轮接续宿主独立流程，
实现作者声明组件后，用户跨插件选择组件、配置模型及流程，并真实按选择加载。
架构与质量两位独立评审均已确认以下契约可实施。本文是设计，不代替最终验证结果。

## 声明与选择

- 仅 native Mods manifest 显式 opt-in：`claw.componentsVersion: 1` 和 `claw.components`。
  组件包不能混用原 `entry`，公共初始化须声明为组件并通过依赖显式选择。
- 组件包含稳定 `id`、`name`、`kind: "module"`、独立 `entry`、`dependsOn`、`actionIds`，
  可有说明和 `configSchema`。依赖限同包，拒绝循环、缺失、重复、路径越界与入口别名。
  每个导出动作必须唯一归属一个组件。kind 是目录分类，不是权限隔离。
- Claw capability 保留原包身份与摘要，增加可选 `components`：`mode`、`ids`、`config`。
  缺省保持整包；selected 模式必须非空并显式包含全部依赖，不自动回退整包或暗中加依赖。
  页面展示依赖并提供加入操作，配置只对选中组件生效，后端验证真实 schema。
- 未声明组件的旧插件继续整包，旧摘要与旧 Claw 规范化不变，不静默迁移。

## 真正按选择加载

- 授权固定全部组件源码的完整包摘要。各入口独立编译，从同一个不可变源码快照生成运行包；
  未选入口的顶层代码和 register 均不执行，不靠隐藏 UI 或过滤注册结果实现。
- 禁止直接或经公共模块静态导入其他组件入口，以解析后的真实路径校验；组件间依赖由宿主
  按确定的拓扑顺序调用 register。公共辅助模块可导入，但跨独立 bundle 不共享模块实例。
- 一个包仍使用一个真实 grant 和 guest。运行投影固定有效组件、配置、选集摘要、客户端模块、
  环境声明与动作；所有命令、Hook、工具、站点及 provider 使用同一投影。
- 配置只传给对应组件；不创建新的权限、凭据或宿主身份。组件不是独立沙箱，也不支持自动拆分
  任意旧 Hook。来源目录发现不执行 guest，编译受原有源码和包级资源限额约束。
- 原有首次批准和主动兼容探针仍在无业务执行权限的独立 guest 加载全包并检查 register。
  “未选入口不执行”限定实际业务会话，不把批准时注册探针说成零执行。

## 兼容、撤权与证据

- 保存延用 revision CAS，应用冻结副本；修改模板不改变当前会话。应用选择变化使旧实例、审批、
  回调和在途结果失效。运行证据保留真实包摘要，并增加组件选集与配置摘要。
- 插件强制 check/repair 完成规则要求整包模式；保存、应用、设置规则和运行时一致检查。
  使用真实线程绑定，不能以旧全局 active 或仅存在包名为依据绕过规则。
- 动作准备和执行均验证动作归属；客户端资源同样按投影收窄。审计记录可信有效组件集合和
  选集摘要，不把 guest 自报值当来源，也不声称每次调用精确来自其中一个组件。
- 普通本地会话边界不变，传统 Plugin/Harness Flow adapter 不在本轮开放。

## 验收

双人设计评审后分工实施并交叉代码检视。验证未选入口顶层副作用零执行、依赖只初始化一次、
跨入口导入拒绝、配置/schema/摘要/CAS、动作与客户端越权、强制规则、切换与撤权。
真实 Electron 演示跨包组合并从聊天使用，截图记录依赖和配置页面；继续覆盖旧包、旧 Flow、
Plugin/Harness、类型、构建、全量 Vitest 与九条独立链。历史失败逐项对照，不宣称全仓全绿。
