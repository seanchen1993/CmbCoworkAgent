# Pane 初始焦点请求的生命周期

面板关闭或替换后，renderer 会移除已经离开当前面板快照的初始焦点请求 ID。反复在同一任务打开、关闭带焦点请求的面板，不再一直累积旧 ID。当前面板上的请求仍保留去重记录，包括已结束但仍出现在快照中的请求，避免旧 pending 快照触发重复执行。

组件清理时清空记录；新的线程快照加载前不尝试旧快照的焦点。主界面原本已按线程 ID 重新挂载组件，后一个检查用于保护组件生命周期，并非已确认的主界面跨线程漏洞。

没有修改宿主焦点确认、用户键盘归属、取消、撤权、generation 或原生 composer 行为，也没有扩展支持的 UI site。这是已有桌面 Pane 的资源清理修复，不代表此前长稳 ACK 超时的原因已经找到。

新增回归在 Electron 的临时 iframe 中运行实际 FunctionPanes 和 React，观察 32 次关闭后的请求集合、重复快照、已完成请求、线程属性切换及卸载。iframe 的宿主回执由测试控制，因此该测试只证明 renderer 行为；真实 guest/session、普通 Electron 焦点与关闭对照仍单独验证，详见验证报告。
