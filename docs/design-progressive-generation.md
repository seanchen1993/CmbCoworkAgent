# Design 渐进生成与 Tweaks

实现日期：2026-10-23。

局部 AI 改稿已增加独立的补丁执行链路，详见 [Design 局部补丁实现](./design-local-patch.md)。

## 页面生成

新页面通过同一次 Agent 执行完成：先写闭合的 HTML 骨架，再按语义区块使用 edit_file 补齐。成功写入后的回调读取稳定文件快照；相同内容去重，短时间写入合并。每份草稿包含运行身份和递增版本，旧运行、旧候选路径和迟到的读取结果不能覆盖当前页面。

使用 `data-design-section` 标识稳定区块，`data-design-pending` 与 `data-design-build` 标识未完成内容。闭合骨架可以预览，存在未完成标记或缺失预期区块时不能定稿。合法的未完成草稿继续在原线程补齐，不进入更换新文件的写入恢复路径。

预览在同一个 iframe 内应用区块补丁；框架外壳变更时使用完整快照。补丁带基线版本和 ACK，丢失补丁或基线不一致会从最新完整快照恢复。草稿只运行宿主预览代码，页面自身脚本、事件属性与嵌入内容在草稿中不执行。定稿完成资源处理后加载一次，开放业务交互。

用户可以查看区块进度、滚动预览，以及在草稿和已有定稿之间切换。离开页面不终止任务；停止、失败和异常退出保留最后可预览草稿，并标记未完成。正式版本与草稿分开保存。

## Tweaks

新 HTML 在一个 `script[type="application/design-tweaks+json"]` 中声明 defaults、schema 和 bindings。模型不再生成通用控件面板与通信代码，宿主提供面板和独立运行代码。

- 支持颜色选择与文本输入、数值滑块、文本、布尔开关、下拉选择。
- 支持 CSS 变量、专用叶子文本节点和显示/隐藏绑定；数值单位由绑定声明。
- 用户值作为 overrides 保存，保留重置、撤销和重做；不因单个参数修改重新加载 iframe。
- 生成期间可调整全局参数和已经就绪的区块参数；未生成参数不可编辑，最终校验期间暂停编辑。
- 区块替换、预览恢复和重新进入会话后重新应用当前值。完成瞬间排队的微调只允许归入同一个运行产物，不会修改其他运行。
- 模型的 `resetOverrides` 声明用于本轮明确要求更改的参数，其他用户调整继续保留。不兼容的旧参数值单独保留。
- 导出、最终校验和下一轮 AI 修改使用同一个 HTML adapter。普通 HTML 与资源包导出包含当前有效值；下一轮模型读取的源快照也包含该值，并省略可由宿主补入的通用运行代码。
- 历史 EDITMODE 页面继续使用原适配器。原有方案切换面板与新的参数面板分别保留。

已完成区块出现前仍可能有必要的资料读取；分段生成增加了工具往返，不能仅凭本地验证承诺在线模型的首屏或总耗时。

## 保存与事件

SQLite 新增 `design_draft_previews` 保存当前草稿 HTML。会话 JSON 和事件日志保存草稿元数据，不重复放入整份草稿。对同一草稿版本的进度和微调事件，IPC 省略未变的 HTML；客户端使用已缓存内容，缓存缺失时请求完整快照。

微调值的事实来源是主进程会话存储；正式产物的 artifact.json 同步保存文件侧投影。保存失败保留当前面板的未保存状态并支持重试，导出或开始下一轮生成前必须提交待保存参数。

`generationMetrics` 记录开始、首个文本输出、首次成功写入、骨架可见、首个有效区块可见、最后区块可见、校验与完成时间，以及草稿数量和字节数。可见时间由渲染进程确认。真实模型的输入输出 token 与不同场景的 P50/P95 尚未采样。

## 验证

- `npm run typecheck`
- `npm run build`
- `npm run test:design-sessions`：36 个单元测试与真实 React/Chromium 回归。
- `npm run test:design-html`：原有完整文档和多方案的资源、脚本、表单、Canvas/SVG、下载、视口与编辑回归。
- 新增模块和会话管理模块通过 ESLint。

浏览器回归覆盖区块更新保留 iframe 与未修改节点、草稿业务脚本不执行、微调值随区块保留、丢失补丁后的完整快照恢复、后台重进、定稿脚本只执行一次，以及定稿后的微调不重载页面。单元测试另覆盖草稿去重、非法/迟到草稿、取消、回滚、SQLite 重开、最终标记检查、微调版本/重置/撤销及异常退出后的草稿解锁。

验证使用确定性模型替身和本机 Chrome，没有调用在线模型或真实外部业务服务。可通过 `CHROMIUM_EXECUTABLE_PATH` 指定 Chrome；未指定时使用 Playwright 浏览器。
