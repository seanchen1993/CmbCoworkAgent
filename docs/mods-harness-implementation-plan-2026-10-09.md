# Mods 与 Harness 研发任务闭环实现方案

本方案在 `codex/mods-v2` 上交付可组合、可恢复、可验收的研发助手。保留 Electron、React、TypeScript、LangGraph／DeepAgents、QuickJS 和现有项目 Harness，吸收 DeepSeek Harness 的能力接口、生命周期和持久执行事实设计。按用户后续确认的节奏，关联能力连续分批实现，再集中代码检视和完整回归；过程中只做必要边界窄测。各批保留独立验收证据，全部批次完成后才能宣称本方案交付。

## 核心约束

### 能力与执行入口

用 TypeScript 明确区分能力声明、宿主实现和调用方。所有新增调用保留 workspace、thread、run、step、execution、parent、source 和配置版本；身份由主进程产生，Renderer 与插件不能自行授予执行权。

复用现有工具审批、租约、撤权和最终参数校验。普通工具、MCP、Mods、CodeExec、Flow 与子任务逐步接入同一类执行记录；新增包装层只委托原执行器，不直接调用工具绕过已有策略。只读查询不能冷启动执行器、建立新连接或产生模型费用。

插件生命周期清理必须覆盖注册、计时器、面板、后台进程、取消回调和待完成请求。旧版本异步结果不能更新新版本状态；撤权立即阻止后续调用与发布，不宣称撤销已经完成的外部副作用。

### 持久运行与恢复

保留原 checkpoint 的模型运行快照职责。交付事实保存运行、步骤、配置、调用和证据之间的关联。UI 是持久状态的展示，不是事实来源；流式临时片段与已结算结果分开。

恢复分三类：

| 状态 | 恢复规则 |
| --- | --- |
| 已结算且产物、配置和依赖未变 | 宿主重新验证后可复用；明确标记来源运行 |
| 尚未执行且前置步骤有效 | 重新取得当前授权、租约和预算后执行 |
| 已进入执行但没有可靠结算 | 标记结果不明；提供核对材料，不自动重放副作用 |

恢复入口必须由用户明确发起。用户已经授权本轮开发自动分批推进，不等于替产品用户自动恢复业务操作。

第一版只开放能够证明安全的 Flow 恢复路径。配置快照不一致、来源撤权、产物改变、未知工具结果、旧结构缺少必要证据、循环路线不可唯一确定时，返回具体原因和重新运行建议，不伪造可恢复状态。

人工审批 nonce 不跨进程复用。恢复后重新生成审批，审批摘要绑定当前产物与结果；最终提交／业务阶段推进必须重新检查，已完成外部提交不能仅凭 UI 状态重复调用。恢复次数与已消耗执行次数纳入同一预算，不能通过重启清零规避限制。

Worktree 恢复必须验证路径仍归属本任务、分支／HEAD／工作区指纹与持久记录相符。未达到此要求前保留当前明确的重跑行为，不自动删除或合并旧工作树。

### 兼容检查与版本

事件可以注册、SDK 可以调用、宿主实际可用、完整场景验收通过分别表示。`--strict-compatibility` 必须检查已经发现的 SDK 不兼容，不能只因事件提供者存在返回成功。

增加静态 SDK 使用报告时，不执行作者 Hook 进行探测，不借扫描结果授予权限。报告区分明确的字面量调用、无法分析的动态访问、版本限定参数；未知调用方式标记未验证，不能宣称完整安全扫描。继续支持现有作者类型检查。

UAT 已有插件入口保持可用；本分支 native／legacy Mods 协议可以纠正和简化，涉及已保存内容时提供清晰迁移。最新 Claude 示例的模型返回结构、timeoutMs 和工具字段差异给出明确迁移提示。协议变更应显式选择、更新示例并完成回归，避免运行中悄然改变已批准能力。

### 持久化与升级

新增结构有 schemaVersion、输入校验、大小与数量上限。旧数据通过只读解释保留原含义；缺少恢复证据时禁用恢复，不猜测结果。迁移前有备份，失败保留旧数据。UAT 已有插件、项目、Harness、IM、Goal、定时和普通聊天功能及默认语义保持一致；Mods 的流程、样式和接口按本方案直接优化。

新功能按真实宿主能力开放。关闭 Mods、开启但无插件、启用普通插件、应用 Claw、启动 Flow 是五种不同验收状态，不能互相替代。

## 实施批次

### B0 固定基线与发布检查

记录 Git 状态、修改前文件摘要、Node／npm 版本和测试环境。修复本轮发现的测试宿主类型问题，不弱化断言。运行当前源码类型检查、Mods／Flow 核心测试及完整 `npm test`，保留首轮失败。对失败按现有基线、环境、真实回归分类；无法定位的失败不写成通过。

产物：基线清单、可复跑命令、失败账本和修复。退出条件：本轮变更相关测试与 Node／Web 类型检查通过，完整回归结果已分析；任何存量行为回归修复后才能进入发布。

### B1 SDK 兼容诊断与能力清单

在 `src/main/mods/devtools` 增加有界静态 SDK 使用分析，复用 loader 的不可变源快照和现有作者声明。先覆盖直接调用与可确认别名；动态索引、传递整个 SDK 等无法证明的方式标记未验证。SDK 方法支持目录与事件支持目录分开，明确 ui.ask 等 SDK 操作不一定是同名引擎事件。

`check/inspect` 返回实际调用清单、来源文件位置、模型协议及不兼容原因；strict 模式对明确不支持与未验证访问返回失败，普通检查保留包结构结果和诊断。补充官方模型协议／isDeferred 参数的诊断，生产语义支持必须单独验收后开启。

产物：CLI 报告、专项测试、当前支持范围说明。退出条件：audio.speak 等不可用 SDK 不再获得严格通过；支持的已有示例继续通过；扫描不执行 Hook、不读取插件外文件、不能因注释或普通业务变量误报。

### B2 Flow 中断诊断与恢复契约

新增有版本的恢复计划模型与纯分析器，给出可复用步骤、下一步、失效原因和需要核对的操作。先接主进程只读查询与运行详情，不启动业务操作。分析依据原始 Flow 快照、当前执行计划、产物指纹、attempt epoch／路线和真实终态；缺少信息不猜测。

产物：恢复计划、IPC 输入验证、中文解释、运行详情入口。退出条件：成功、失败、取消、等待审批、未知执行、修改文件、升级插件、切换模型、撤权、旧数据和复杂路线均有真实边界回归；只读查看不改变授权和业务状态。

### B3 安全续跑与持久交付记录

基于 B2 的计划增加显式恢复命令，创建带父运行关联的新运行并再次验证源版本、产物和授权。第一版按可证明的连续有效前缀复用，审批重新请求、最终检查重跑；复杂条件／重试路线在有完整游标记录前明确不可恢复。

执行前持久化计划和本次 executionId，执行后保存结算及证据，再发布 UI。记录进入宿主、结算、取消和结果不明；不能把网络丢回执当作未执行。恢复有 CAS／租约防重复启动，不跨项目或对话借用结果。关联记录有容量限制和不破坏活动运行的保留规则。

产物：主进程恢复实现、preload／Renderer 操作、关联历史、故障注入测试。退出条件：真实进程重启后可以继续受支持任务；重复点击、崩溃窗口、撤权、旧审批和结果不明均不能重复触发外部操作；明确停止的用户取消任务不被自动恢复。

### B4 统一执行证据与验收

扩展现有调用回执和 Trace 的关联字段，将普通工具、MCP、Mods、CodeExec、已知子任务、Flow 接入可查询的交付证据。优先复用现有 control-store 和 checkpointer，不另建一套竞争性消息历史。证据只保留必要的受保护内容，凭据不进入事件。

将完成规则绑定本次实际代码／产物指纹、运行和检查配置；修改产物后撤销旧 PASS 的有效性。模型检视、原生测试和人工验收分别展示；失败修复受次数、总时间和执行预算约束。业务阶段推进只使用最终新鲜证据。

产物：统一查询投影、工作台证据展示、入口一致性回归。退出条件：主聊天、Flow 和 CodeExec 子调用都能追溯原始执行；伪造输出不能生成真实检查证据；上下文压缩／刷新不会改变已结算执行事实。

### B5 组件创作与可管理版本

基于已有模板、作者类型检查、安装和 Claw 组件表单，提供从描述／模板到源码、检查、独立预览和安装的连贯入口。生成的组件与用户手写组件走同一套授权和执行。支持命令、工具、规则和面板模板，以及固定输入输出的 Flow 动作模板。

安装前显示能力、兼容报告、组件依赖、配置及模型用量影响。更新显示版本差异，运行中的任务绑定原版本，空闲后显式应用新版本。回退恢复插件／配置版本，已发生的业务副作用按记录核对而不宣称自动撤销。

产物：最小创作向导、独立预览、三个可安装示例和更新／回退验收。退出条件：公开 UI 从创建到首次运行、更新和回退走通；取消创作不改变已应用组合；用户无需编辑主工程即可获得新组件。

### B6 基于评测的优化与整体验收

复用现有 Trace／Skill Optimizer，增加候选与基线绑定、固定任务集、隔离工作区执行和结果比较。先开放 Skill／Prompt／流程配置候选，不自动修改核心运行器、权限策略或沙箱。分别记录任务验收通过率、人工接管、耗时、模型用量和检查证据，不用模型自评分代替实际结果。

在 UI 展示候选收益与退化，用户选择应用或保留原版；失败可回退配置。真实模型评估需要已配置可用服务，受控模型测试只证明调用与状态机，不包装成业务质量结论。

产物：评测契约、候选比较、隔离执行与版本应用入口。最终验收：同一安装包完成真实研发任务的计划、修改、独立检视、原测试、有限修复、中断后核对续跑、证据检查和人工确认，并回检旧 Plugin／项目／Harness／IM／Goal／普通聊天。受外部环境限制的项目逐项保留，不能标记方案全部完成。
