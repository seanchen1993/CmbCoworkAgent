# 项目依赖组件分组验收（2026-10-31）

默认插件列表只突出项目插件和无关的独立插件。被项目引用的组件收进该项目“依赖组件（数量）”，默认折叠；主插件开始使用后仍在项目设置中统一配置、一次确认本次项目所需权限。没有新增授权途径或业务名称特例。

关系来自实际原生项目runtime和action lock中的已安装pluginId，不按文件夹或AutoBiz名称推测。一个组件可以由多个项目共享；本身也是项目的插件仍保持独立入口。停用项目不会解除依赖关系；卸载最后一个引用项目后，原依赖恢复普通列表可达。无效或不完整声明不隐藏任何普通插件。

依赖区不再显示独立“开始使用”和逐个授权入口；保留管理、停用、恢复启用和卸载用于维护，并提示共享组件影响。启用组件只恢复可发现状态，不授予运行权限。经典插件列表也同步分组，搜索依赖名可以找到所属项目并展开管理。
